# 成熟接收状态与全局／共享供体隔离协议

本轮只检验“给定已付费全局阶段，新增供体渠道是否能改善成熟接收者的一轮联合局搜”。保留四职责、QGS、FA家族及原共享生成规则，不改默认主线，不启动Goal或后台调度，不将短程探针称为完整算法比较。

## 先核对重复

|旧方案|已检验什么|本轮实际区别|
|---|---|---|
|首轮父代局搜 PRE_FIRST|首轮局搜改从QGS前父代出发，随后恢复串行|本轮四臂接收者完全相同，只改变供体集合；不是改入口的频率或轮次|
|已完成供体反馈 ALL/OWN/SYNC|普通直接内核中，同代已完成局搜状态是否可见|本轮原live R语义全部保留，额外来源是同一轨迹已付费的全局／共享候选|
|静态已付费供体 GRAFT_S|独立来源50k的ND100槽，接入从初始解重启的普通PA50k|本轮是成熟SHARE_CTX_GOM的同轨迹条件探针，固定接收状态、模型和共同已付费档案，区分G/S并保留原家庭合法域|
|阶段目标偏好干预|改某轮全局／局搜目标偏好|本轮使用实际分组的原方向和原接受规则，全部不变|

**外部付费供体并不是此前没做过的新机制。** 此次是在上一轮Linux阶段诊断的同轨迹成熟状态上隔离供给渠道，不能用换了接收阶段或平台就重启旧GRAFT结论，也不主张新颖性。全局内部已有父子精英选择；这不是补“缺失精英保留”。

## 数据与费用冻结

- 源为上一轮Linux FULL的两个开发实例、三个seed：20_8_5_1、100_2_3_1；16110003、16110037、16110069。它们是已用开发状态，不是新泛化测试。
- 每条选首次实际 PRE_GLOBAL 且成功FE≥250000的边界，保存实际分组的100个成熟P、随后完整5000次全局候选和POST_GLOBAL的全部已付费非支配档案A0。不按质量选窗口，不使用该边界之后的搜索结果。
- 旧记录没有完整供体四向量，故六条各500k观测重放实际新增300万FE，必须与旧Linux整条付费SHA、初始解和公共前沿一致。新增观察代码不得调用RNG、评价或写算法属性。
- 每臂只做一个完整100接收者程序轮：20例3820FE、100例19860FE，按实际FOS核对。四臂×三seed×两例共284160科学探针FE。
- 工程189448次尝试，含两次预登记失败；计划合计3473608次尝试。原始来源重放、探针科学FE、工程、导入及物理QA、离线统计分别记账。逻辑比较成本是相同来源前缀加同一局搜轮，后续源重放费用另计且不能供给探针。

## 四臂与不变量

R为原同家庭实时供体，排除接收者自身。G为该5000次中的普通非组装候选；S为已评价的组装候选，两者包含被拒绝候选。四臂为R、R∪G、R∪S、普通R∪G∪S（UNION）。这是同一供给假设的G/S包含关系2×2，用于区分两类增量及交互，没有新增来源选择器。

外部按family和各厂有序(job,MA,WA)物理链去重，剔除与初始R同家庭相同的排程；G/S交叠标GS，UNION只保留一次，稳定按首次付费顺序。不能按目标排序或事后改容量/比例。普通并集可能使R或S被大G池稀释，这属于实际处理效应；必须报告池大小和抽中率，不能把失败泛化为所有付费供体无用。

模型/FOS仅由P学习，外部不加入工作种群或建模样本。接收者实际方向、访问顺序、FA家庭、合法性、完整FOS和原联合混合规则固定。R的已接受工作状态照常实时更新，G/S固定不变。

共享组装只发生在固定家族CENTER请求，free80没有S供给。报告应分固定家族和自由成员；不能用全群平均掩盖没有触发的部分。

每臂将同一A0装入原GomRunScope全付费档案，然后随各自新评价自然演化；不是SearchState个人历史，也不是全程冻结接受参考。CENTER沿用 `weaklyDominates(child,parent) || !dominatedByPaidArchive`，三个专业角色严格改善自身目标。

probeSeed=sourceSeed XOR 0x51d0a7e3。接收重编码、模型与FOS打乱共用同一起点；每个提议用协议里的独立派生Java种子执行nextInt(poolSize)，避免不同池大小的拒绝抽样改变后续公共随机序列。这是新的隔离抽样接口，不冒称恢复原算法RNG。外部中性重编码使用另一套独立种子，所有臂全部构造相同视图，GS重叠使用同一套keys。

## 验收与判断

工程核对原GomLocalProgram与新R_NATIVE在原抽样接口下的完整付费、终工作态和档案相同；R重复一致；G/S/UNION每次付费全时间轴QA；截止1、2、末FE前一位及故意失败2正确收尾。输入导入另做完整物理复核，独立Python重建来源去重、模型/抽样时序、实际混合、每次接受/档案、付费SHA及最终工作态。数学统计仅Linux执行。

主比较UNION/R，辅助G/R、S/R，条件增量UNION/G及UNION/S全部报告。HV使用旧冻结尺度、参考1.5及1.25/2；IGD+/IGD参考为本批同实例四臂三seed末档案共同ND并集，仅离线使用；双向C精确弱支配并附分子分母。并列A0以上新增HV、工作态终点、供体读入/接受/准入和成本，不作加权或多数投票。

沿用小试资源信号：配对中位HV至少1%或IGD+对称改善至少5%，对应例至少两个seed改善，另一例无重大HV−1%/IGD+−5%/C反向10个百分点。此处即使出现信号，也只能支持进一步完整算法验证；短探针没有越过门槛或新增量很小，不能直接推成全局永远无价值。任一上下文外部来源读取少于20次，明确标为触发不足。所有比较完整结束才读取质量汇总，不更换窗口、seed、池容量或来源比例追正。

没有真实TIME_LIMIT质量实验；同时间优势、强经典竞争力、四职责独特性和投稿创新均不在本轮结论范围。旧失败方案、默认主线与全部历史结果保持原样。
