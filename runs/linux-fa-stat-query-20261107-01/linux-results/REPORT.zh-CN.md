# FA统计来源：三臂最小小试结果（2026-11-07）

本轮完成，**固定PRE_FA_STATS方案停止**。原模型对照仅晚入口出现实质距离信号，未在至少两个入口复现；相对匹配随机FOS没有实质优势，晚入口IGD+有明显反向。没有启动live余程或闭环，也不调历史长度、统计混合比例、父代或节点追正。四子群、QGS、固定家族、原共享和默认主线未改；本项停止不否定这些基座及其已有范围内收益。

## 固定干预与零评价检查

实例100_2_3_1、原源seed14910003，三个已付费POST入口104540、179120、228840。每入口按原职责取自由成员中槽号最小的两个父代，共8个，每父代抽16个不同非平凡合并序号，三臂各128次评价。源轨迹没有重跑。

POST_FA使用原POST矩阵/FOS；PRE_FA_STATS只把FA统计（尾部、吸引/排斥分支及外部互信息）换成PRE群体来源，POST顺序内部项不动；RANDOM_FOS是PRE树的一次固定工件重标号，树和逐节点大小相同。输入父代、供体、资源与键值固定，子代会因掩码不同而复制不同字段；没有重新编码或替换顺序信息来源。

零评价机会检查分别126/128、117/128、109/128组物理候选变化，三个入口都覆盖四职责，均通过事前26/128和至少两职责要求。全部1152提议的独立逐字段核对及冻结Java PaMixingMove夹具通过，才开始24父代QA和付费阶段。所有候选独立从固定父代出发，不更新接收者、模型或供体；没有运行完整局搜。

## 接受规则与辅助背景

每个候选独立相对同一固定父代及请求前S档案，按原公式计算wouldAccept：边界职责严格改善对应目标；CENTER弱支配父代或不被档案严格支配。它只用于离线标记，不推进工作状态或接受档案。主结果包含全部付费候选，与原外部结果档案口径一致。

晚入口PRE与POST按原接受公式所得目标前沿完全相同：双向C均为1，HV/IGD+/IGD差均0。PRE的该入口总候选距离信号没有在保留子集出现；中入口二者保留前沿也相同，早入口差值仅HV+0.0000332%、IGD+改善+0.00731%。这限制当前模型变化的直接应用，但不能据此复活已失败的平局、接受或后筛选方案。

同期S∪PA共同档案作为辅助背景另算统一参考，不能和主距离值拼接。相对POST的辅助HV依次约−0.013809%、−0.00000333%、+0.000828%；相对随机依次+0.005469%、−0.001372%、+0.000660%，没有稳定实质新容量。完整辅助三指标和接受子集在analysis/comparisons.json；没有把PA已有质量当成本轮新发现。

## 工程、预算与限制

- 全部实际尝试/成功FE为1152/1152，失败0；额外QA24次全部通过，父代目标逐位相同。原来源重跑FE为0，恒等和重复正常收费，全部回退数为0。
- 独立核验1176份完整时间轴、235200道工序，工序目标聚合误差0.0；实际加载类检查45次，与冻结源码/类/依赖身份匹配。
- 独立HV复算54次，最大差1.07e-14；IGD+复算18次，最大差8.67e-19；双向C分子独立检查24次。实际指标方向、平均距离及原接受公式夹具通过。
- Linux JDK17.0.21、Python3.11，复用原Java8目标编译的评价类，无新算法编译或生产类替换。单JVM顺序，QA进程合计0.305s、候选进程合计4.735s，离线指标约33.185s；费用/负载日志保留，不作同时间质量结论。

三入口是一条轨迹的相关时点，父代仅每职责前两个、每父代16个非平凡掩码。结果限定该固定查询方案，不证明所有模型来源、整个局搜程序或全部FA结构都无价值。零评价机会充分只说明干预被触发，不能替代质量和普通控制。

## 停止决定

事前要求PRE对原模型和匹配随机两项比较，分别至少两个入口达到HV≥0.1%或IGD+改善≥5%，并无重大指标反向。对原模型只有228840有信号；对随机没有合格信号，且228840的IGD+超过5%反向界限。两项均未通过，决定为STOP_FIXED_FA_STAT_SOURCE_HYPOTHESIS。

本轮没有将RANDOM_FOS晋升为新算法，没有扫描其他入口/节点/seed，也没有启动新的机制。此前PRE_FIRST、供体/资源、家族和接受方案的停止保持。更换统计来源确能改变联合块，但本次未证实更有效的联合修改；四子群与原共享的独立研究价值不由这一单因素试验否定。
