# 当前创新主张与局搜后筛选验证协议

本轮先说明当前版本的研究主张，再执行已讨论的三臂隔离小试。保留四职责、QGS、固定FA家族和原共享规则，不改生产默认主线，不恢复Goal或后台实验，不扩实例、seed或扫描参数。

## 当前可以主张什么

|层面|当前设计|证据与边界|
|---|---|---|
|研究主线|动态疲劳下，目标职责分工通过合法结构共享与联合局搜形成协作|已有部分匹配消融正信号，尚未形成跨实例稳定优于强基线的完整方法|
|四职责|工期、能耗、人工成本和综合折中职责|分群思想与原李明哲基础明确继承；不能把四群形式本身称为新发明；部分新配套中的S/U消融有收益|
|条件共享|固定工厂分配家族内共享、组合完整工厂排程，保留合法性|已有局部与部分闭环收益；新G/S供体池、容量扩展和选择器假设的停止不抹去原正证据|
|联合搜索衔接|四向量合法域下联合传递顺序/资源，保留各群接受职责|成熟搜索思想的适配和工程可靠性不直接算独立创新，完整组合竞争力尚待证实|
|问题与计算基础|动态疲劳共同解码器、精确增量重算与严格计费|可靠基础；疲劳特有性、模型新颖性及同时间算法优势不能由正确性推出|

反向传播伴随、教师复杂评分、固定重启、额外供体扩池等未过相应验证的版本，不列为已经成立的贡献。新“局搜后筛选”目前只是假设；扰动后局搜再接受已有迭代局搜和模因算法研究，不以顺序调整本身声称ESWA创新。参考[Geiger多目标流水车间PILS](https://arxiv.org/abs/0907.2993)。

## 新缺口与旧失败的区别

当前每个QGS批次确实有父子联合精英筛选，先按局搜前目标决定保留，再继续QGS与局搜。检验的是此即时选择是否错过后继局搜价值，而不是修复“缺少精英保留”。

- PRE_FIRST直接选择旧父代作首轮入口；本轮同一批真实父子双方分别获得局搜后再筛选。
- R/G/S供体探针只改变可供混合的材料；本轮候选是完整搜索起点，供体规则仍为原局搜live工作池。
- 旧ROLE/CENTER阶段干预改变即时偏好；本轮主臂改变判断时点，普通POST_PARETO才消融筛选职责。
- 代末G+L保留审计不是P与C分别局搜后的比较。

新假设：候选即时排序可能与同费用局搜后的质量不一致，依据后者选择的状态能在后续等预算搜索中形成实质档案增量。只有工作态即时变好不算通过。

## 来源、三臂与预算

复用`linux-mature-donor-20261106-01`六份成熟快照：20_8_5_1、100_2_3_1；来源seed16110003、16110037、16110069。来源已有完整50万轨迹重放验收，本项新增来源搜索FE为0，历史来源300万FE仍披露。

从原始points.tsv按每角色真实连续费用段取第一个batch（15/55/15/15），与PRE_GLOBAL的同角色原组内顺序配对。不得取已去重的外部供体池；保留重复、退化、与父代相同的候选。逐行检查角色、家族、固定FA、索引与真实付费FE。C100来自各角色先后生成的首批，**不是同步生成的100个子代，也不是整个50步QGS出口**。

共同A0是原完整全局阶段结束的已付费非支配档案，不是首批各自出生时的背景。两个实例分别在260880、278560旧FE后已有全部输入；之后的来源状态不读取。结论限于该条件背景，不能认作原算法自然续跑。

|臂|流程|新评价费用|

## 实付新评价前的来源核查限定

六份预定首批都没有直接共享提议（S=0，600份C全部来自G），已在Linux `source-coverage-qualification.json` 中于新评价前记录。保留原取样，不为寻找正结果补抽或改取样时点。本轮只能检验保留原共享历史的成熟状态中，普通全局候选的选择时点；不能检验直接共享提议的局搜后潜力，更不能据此证伪原共享收益。

## 评价与停止

主终点为3B后A0加全部付费发现的档案；所有未选择候选必须保留在结果口径，不能隐藏。辅助为工作种群、2B阶段、前后选择身份与原始/改善后的排序变化，后者不能替代继续搜索的质量。

两例分别使用三臂三seed末档的共同ND并集作IGD+/IGD参考，仅离线使用；原冻结归一化，HV1.5及1.25/2，精确弱支配双向C及分子分母、完整极值向量。主比较POST_ROLE/RAW_ROLE，另报告POST_ROLE/POST_PARETO和普通控制/RAW_ROLE。

继续沿用资源信号：HV中位至少+1%或IGD+对称改善至少+5%，对应例至少2/3重复；另一例无重大HV−1%、IGD+−5%、C反向10个百分点。C明显反向不能靠HV晋升，不作多数投票。普通控制解释收益则不追加角色筛选独特性主张，不自动将控制晋升。没有后继实质增量就停止，不扫比例/窗口/seed/局搜长度。

所有搜索、QA、统计、绘图在Linux；Windows仅开发与接收。记录实际类/源码/输入/依赖/JDK、全费用、进程与外部负载。无TIME_LIMIT、普通NSGA新对照、独立验证实例或论文级泛化结论。单JVM顺序运行，默认主线及全部旧停止保持。
