# 动态疲劳成本与复用协议 v3（运行前冻结）

目标：测量候选首阶段真实重算的费用、接受/拒绝驱动的实际伴随复用，以及合法局部候选在全部搜索耗时下能否优于时间通道和随机。只运行独立标量局部链，不改Java基线、PSO或整套多目标算法。

## 数据与预先指定比较

沿用v1/v2的6个式(8)合格第四章实例、重建SUT/standby、三档合成疲劳参数和异质性seed；新父本seeds为 **17、41、83、173、347**，不与前两轮重合。90个实例/父本/疲劳场景，各诊断TEC和均衡三目标两个方向。标准处理时间和其他模型参数不作干预，全部候选是真实合法的编码修改。

主要比较单元预先指定为：**强疲劳快恢复、TEC方向、固定0.25秒**，完整边界疲劳伴随分别对共享真实首阶段的时间通道、随机。其他场景/方向、固定评价次数与廉价时间通道作为必要完整对照，避免只汇报前轮较好的条件。六个实例簇的统计仍仅作小样本机制证据。

## 四种选择方法

- `cut_fatigue`：每候选真实重算首阶段；直接费用差+旧后阶段边界完整疲劳伴随对首阶段C/v差作线性预测。
- `cut_time`：完全相同的动态疲劳首阶段重算，只在后阶段伴随中停止疲劳状态反向。共享相同费用，隔离后阶段疲劳通道的价值。
- `local_time`：保留v1旧状态局部defect+时间通道的廉价评分，检验真实首阶段增加的计算是否值得。
- `random`：在同一个合法局部池规则中均匀抽一个候选，不建立伴随、不重算所有首阶段。

每池16个单工件机器/工人修改或同厂相邻顺序交换，FA不变，资源属性随工件移动。候选分布、顺序、seed与v2 `legal_local`严格一致；新生成器先产生轻量描述，仅为入池16个候选创建完整编码，避免共同生成开销掩盖方法差异。数值首阶段使用同一 `_transition`，省去评分不需要的逐工序日志；每次评分保留合法性检查。新内核逐项与旧日志版/完整解码核对。

## 真实轨迹与缓存

各方法从相同初始编码出发，步号控制候选seed，共用选择随机流。最低预测分平局均匀抽取；随机也每步抽取一次。每步只完整解码选中的一个子本，不计算其他候选全真值。选择不读取事后拓扑标签。

各链初始目标向量作为整个轨迹固定归一化尺度；真实标量下降超过1e-10才接受。接受后父本/版本同时更新，缓存立即失效，下次需要时再重建；拒绝才复用旧缓存。不为最后一个被接受但不再搜索的父本预先建立无用伴随。接受路径不同后，后续父本和候选池自然不同，不再声称所有轨迹池逐项相同。

实际q=一次构建覆盖的评分池数，包含首次使用；重复命中次数=q-1。记录每个父本版本、缓存建立、使用、接受终止或预算终止。预算结束仍未接受的epoch是右删失下界，单列，不与已接受终止epoch混淆。随机不伪造q。

## 两类预算与全部搜索计时

- 固定评价次数：24个决策，每种方法均初始解码1次+选中子本完整解码24次，共25次完整FE；首阶段部分评价另外记录并计入时间。指标为最终真实收益、完整实测耗时及收益/秒。
- 固定时间：0.25秒，计时从初始解码/RNG初始化开始。完整包含候选生成、缓存建立、所有首阶段/局部defect、边界投影、随机平局、子本全解码、真实接受/失效和内存审计记录。
- 决策不抢占。仅全解码/标量计算在截止点之前完成的子本允许接受；之后完成的改进不进入限时成绩。保存超时尾部实际费用，实测收益率分母含尾部耗时，不把较慢决策越界获得的改进计入成绩。
- 公共实例加载、磁盘JSON输出、独立组件校准及离线QA不属于搜索计时，来源和额外调用分别公开；不将这些额外真值借给搜索。内存步骤记录和正常循环开销已计时。
- 单进程、单线程串行运行，不启动后台服务。各profile/target/budget块内轮换方法顺序，避免一直让某方法占据相同运行位置。

## 组件校准与实际复用消融

90个初始场景分别核对16候选的数值首阶段与旧日志版C/v/费用，一次预热+5次批计时；单独测初始完整minimal/trace解码和共同候选生成。校准不选择参数，不调整预算。

在强疲劳快恢复、TEC、固定24步的全部30个初始父本上，另跑每步重建的 `cut_fatigue_fresh`：候选、选择、接受和最终轨迹必须与缓存版逐项一致，仅费用与构建次数不同。30条消融与主方法在块内轮换顺序，不筛选只展示节省时间的pair。
