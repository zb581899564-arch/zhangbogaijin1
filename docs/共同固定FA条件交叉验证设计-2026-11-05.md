# 共同固定FA的条件交叉验证设计（2026-11-05）

执行状态：已按冻结门槛完成，两个实例均失败，见[结果与停止决定](共同固定FA条件交叉结果-2026-11-05.md)。以下保留原事前设计，不回写阈值或改判。

## 先验证能力，不直接拼算法

当前 [FA审计](FA修改覆盖与档案产出审计-2026-11-05.md)的顺序信用，不足以证明“NSGA负责分配、四群负责厂内”这一组合有效。本设计提出一个新的解释性问题：**在同一合法FA、同一初始JS/MA/WA和预算下，四职责的条件搜索是否优于统一偏好及NSGA？** 原“稀少但≥30%高产”模式仍为失败；本设计不增加FA预算、不测试原失败的预算重分配，也不直接恢复共同100人父本池。

H0：通道优势是路径和记账方式造成，固定FA后没有稳定的四职责收益。H1：固定FA后四职责在JS/MA/WA上的收益仍独立存在。只有支持H1，才有理由进一步讨论分配上下文价值与专业条件搜索的架构解耦。这里不把完成子任务等同于完成最终完整算法目标。

## 输入与比较

1. 原两个开发实例和动态append共同解码器、三目标、SUT、疲劳参数不变。FA固定只是该诊断共同附加的可行域约束，所有比较方法相同；不是改变默认模型或扩大表示。
2. 预定从自然局搜seed12390003的FULL/NSGA在5100FE前沿各取C、E、W极值及冻结尺度下三目标等权和最小值对应的FA。并列按四向量字典序；同FA精确去重，保留所有来源/方向标签，不另挑替补。最多每实例8个、共16个不同FA上下文；源来源不是独立测试数据。
3. 新条件搜索seed预定12790003/12790033。每个FA的100个初始四向量由同一生成器/seed产生，按job覆盖目标FA后共同合法化MA/WA；必须在所有臂逐编码逐目标相同。不使用来源的原JS/资源作为额外热启动。
4. 三臂为FULL_FIXED、UNIFORM_FIXED、NSGA_FIXED。前两者保留原四物理群、Q、共享和家族规则，仅偏好消融；NSGA保留真实经典繁殖和生存。每臂5100成功FE=100初始化+5000全局，未进入深局搜。最大96条、489600机制FE；不把此短程子问题称为完整算法优越。

## 必须先解决的工程语义

[实际加载变异器和初始化类身份、冻结原文](../runs/fixedfa-source-contract-20261105-085918-475048/)已零FE核对；JobAlignedResources、JobAlignedPaperKernel、ClassicVariation、FamilyContexts和DynamicEvaluation均来自night-research冻结cp-0。尚未实施约束版本。

- 固定FA按job，不是把位置FA向量设常数。初始解在CooperationSupport建立家族之前已有目标FA，这样四个保护标签的FA也相同；标签/配额仍保留，不能据此宣称四个不同FA供给的合作价值。
- 只在隔离副本增加明确的“禁用工厂变异”开关。JOB_ALIGNED与经典核均按job继承FA，同一上下文亲本的工厂交叉不改变FA；必须同时关闭两边真正产生新FA的变异。不能只限制四群或仅在评价后悄悄修回FA。
- 其他JS、机器、工人操作和真实Q/选择语义不变。禁用FA会改变后续随机流，因此只保证同初始化，不声称两方法候选或后续随机流相同。全部构造、合法化、档案和观察费用计入运行。
- 每个付费评价前检查完整FA是否仍等于目标。任何漂移立即保留失败并停止工程，不通过额外投影/修复偷偷改变此次可行候选。完整动态解码/目标合法性与已付费编码仍须QA。
- 开关OFF先以原入口/隔离副本各5100FE，在两实例两方法核对完整付费SHA、前沿、编码和计数；计划40800工程FE。只有确认为同一全局内核且固定FA每次评价合法，才运行性能臂。OFF不是在旧结果上回写。

## 初步推进标准（新结果前固定）

每实例以不同FA×新seed为开发配对，不当成独立实例做显著性检验；来源方向的重复标签不增加独立样本数。HV采用原冻结尺度/ref1.5，另1.25/2.0；IGD+使用同FA同seed三臂并集。

要继续讨论条件分解，两个实例均须：FULL对NSGA的配对HV中位至少+0.5%，至少60%配对非负；对UNIFORM中位至少+1%；两个FA来源各自对NSGA中位不低于−1%；IGD+对NSGA的对称变差中位不超过5%；实际搜索费用中位比不超过1.25。敏感性参考点对NSGA中位不得转负。缺失/失败不靠补FA或seed填满。

通过只支持条件搜索问题，下一项仍须另定完整算法、真实限时、原共享/SYNC及Li规范重建对照、角色消融和新实例seed；不能自动实施FA上下文刷新、新选择器或发布。失败则停止这个固定FA条件优势假设，不加预算、换FA模板、换mask或改seed追正。

## 近邻与创新边界

[2022 CVNS原文](https://www.nature.com/articles/s41598-022-19215-3)已有两个协作VNS及邻域/全局操作配合；[2020 CCA出版记录与摘要](https://www.sciencedirect.com/science/article/pii/S0950705120300381)已有EDA和IG按熵/多样性协作。因此一般“分工、分解、混合”不足以作为新贡献。

[2026 TLKEA作者稿](https://www.nature.com/articles/s41598-026-43257-6_reference.pdf)第7、28、34页给出Q学习、知识全局搜索和块局搜的两阶段设计。这里仅核查与拟议方向有关段落，不声称完成整篇审读；网页正文入口受限，实际读取的是出版社公开作者稿，未下载到本地。

若未来推进，可能的差异只能来自**可验证的FA条件价值和四职责协作机制**及其完整成本收益，而不是把上述常见框架换名。当前尚无这种结果，尚未实现新完整算法，goal保持active。
