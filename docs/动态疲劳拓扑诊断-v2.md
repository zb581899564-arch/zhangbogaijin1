# 动态疲劳拓扑诊断 v2：局部导数可靠，离散编辑需区分三种误差

本轮完成了拓扑/分支分层和预先固定的三段误差对照。**反向传播本身在平滑小扰动上准确；上一轮离散编辑预测不准，不能只归因于后阶段重排，首阶段用旧状态作局部近似也是重要来源。** 合法局部编辑比大范围换序更适合引导，但完整疲劳伴随的成本优势仍有条件，当前继续保持独立诊断，不接入整套Java算法。

## 做了什么，哪些证据是新的

沿用共同动态疲劳解码器、SUT重建及三档合成参数，换用未参与v1的父本seeds **11、29、67、137、307**。6实例×5seed×3场景=90个case；每case有四档连续处理时间微扰池、合法局部编辑池、合法较大编辑池，共5760个观察。连续ST微扰是敏感性探针，不是算法可以改变的决策变量。

完整选择器和time_only均复用v1物理/伴随代码。新增代码只在 `research/fatigue_topology/`：`trials`生成干预/候选，`counterfactual`重算首阶段和固定后阶段，`scoring/diagnostics`负责评分及标签，`case/experiment/timing`负责先预测后观察和计费，`summary/analyze`负责配对分析与审查。未修改Java基线或旧运行结果。

新增6项相关检查通过，覆盖原调度还原、首阶段与完整解码一致、固定资源链可行、探针对照等价于旧图replay、阶段边界一阶预测和合成端到端输出。开发中一次“必须严格等于0”的测试断言出现 `8.816e-17` 累加顺序误差，调整为1e-14浮点容差后通过；没有为此改变物理公式或重跑实际实验。v1的有限差分证据继续保留，本轮没有把它重复计为新样本。

原始记录：[本轮目录](../runs/fatigue-topology-v2-20261031-162700-586634/)、[冻结协议](动态疲劳拓扑诊断协议-v2.md)、[完整机器汇总](../runs/fatigue-topology-v2-20261031-162700-586634/summary.json)、[合并描述表](../runs/fatigue-topology-v2-20261031-162700-586634/report.md)、[记录审查](../runs/fatigue-topology-v2-20261031-162700-586634/audit.json)。

## 连续微扰：图和分支稳定时，疲劳反向非常准确

以下是均衡三目标方向合并三档疲劳的描述。WAPE定义为 `总绝对预测误差 / 总绝对真实变化`，表内用百分比表示；不是相对于完整目标值的误差。

|ST相对变化幅度|全图及活跃分支均保持的探针数|完整疲劳伴随WAPE|时间通道WAPE|
|---|---:|---:|---:|
|0.001%（epsilon=1e-5）|720/720|0.000042%|12.205%|
|0.1%|719/720|0.004207%|12.204%|
|1%|693/720|0.041781%|12.275%|
|5%|631/720|0.179173%|11.547%|

完整伴随的误差随幅度缩小而下降；停止疲劳反向后的误差没有同样消失。这支持疲劳链式导数的实际作用。另存的纯 `grad_base*delta_base` 切线预测也呈相同趋势，不只依赖局部defect的非线性重算。

但小幅度不保证拓扑一定不变：0.1%幅度有1个探针重排，1%有16个，5%有63个。在发生重排的1%和5%组，完整伴随WAPE分别升至 **97.61%、90.51%**；固定的分解中，后阶段调度改变项占绝对分量和约99.98%、99.81%。另有图不变但分支/终点改变的11和26个探针，均衡WAPE分别4.91%、10.79%。

这些标签是事后观察，不能把“真实图稳定”当成在线免费可用的筛选器。并非每次分支改变都会影响所有目标；原始记录保留具体改变位置与终点标志。

## 合法离散编辑：首阶段近似是另一个主要误差来源

合法局部池有1440个候选，其中后阶段图/分支均相同416个、图相同分支改变37个、图改变987个；较大池对应106、17、1317个。合法编辑可能已经改变首阶段图，因此这里的“图相同”专指后阶段，不能冒称整张图都没变。

预先固定的诊断量是：`P`=v1廉价预测，`C`=真实重算首阶段后在旧后阶段边界作线性预测，`B`=真实首阶段+固定旧后阶段资源链的非线性重算，`T`=完整ECT/FAM真值。逐条保存并检查：

```text
T-P = (C-P) + (B-C) + (T-B)
       首阶段近似   旧后阶段非线性/max   后阶段调度改变
```

`C`和`B`有额外计算，都是诊断对照，没有偷偷替换廉价选择器。`B`仍按新的前驱时刻和疲劳重新排程，具有可行时间轴。

|均衡方向分组|数量|原廉价预测WAPE|真实首阶段+边界线性预测WAPE|
|---|---:|---:|---:|
|局部编辑，后阶段图/分支均相同|416|33.04%|1.49%|
|较大编辑，后阶段图/分支均相同|106|28.04%|2.79%|
|局部编辑，后阶段图改变|987|147.30%|85.34%|
|较大编辑，后阶段图改变|1317|545.09%|214.87%|

后阶段没有变化时，真实首阶段重算能显著降低误差，说明不能把原误差都归到后阶段重排。机器/工人替换和换序虽只涉及少数编码位置，却可能让首阶段前驱状态变化很大；旧图伴随配合旧前驱局部差只能作一阶近似。

在固定分解顺序下，全部合法局部编辑的三段**绝对分量和**占比为43.26%、31.64%、25.10%，较大编辑为53.92%、26.86%、19.22%。这些分量有抵消，比例不等于唯一因果贡献；它们说明首阶段近似、旧图内非线性/max及后阶段重排都值得区分。仅将首阶段算准也不能解决所有重排误差。

按编辑类型事后分层，较大池联合换序/资源交换的均衡WAPE为11.78倍、单独顺序交换7.70倍、工人交换1.37倍；这是描述性定位，不据此筛掉失败类型重算成绩。

## 预测准确与值得花时间是两回事

三种主选择始终在预生成的完整池上比较，未按真实拓扑标签挑选候选。各方法均匀处理平局，采用相同拒绝变差规则。

下表为均衡方向跨三档场景的描述平均；收益是父本归一化标量下降，成本是每父本仅用一次伴随的q=1组件代理，不能当作完整搜索速度：

|候选池|方法|池内Spearman|平均接受收益|决策成本代理|
|---|---|---:|---:|---:|
|合法局部|疲劳伴随|0.545|1.454%|16.46ms|
|合法局部|时间通道|0.462|1.348%|15.88ms|
|合法局部|随机|—|0.279%|10.19ms|
|合法较大|疲劳伴随|0.155|0.637%|13.53ms|
|合法较大|时间通道|0.129|0.545%|12.94ms|
|合法较大|随机|—|0.273%|7.01ms|

局部池比大范围编辑更容易排序；完整伴随本轮的平均收益和单位代理时间收益有改善。但在全部合法池/场景/目标方向的q=1对照中，没有完整伴随相对时间通道的收益率差描述区间完全高于0。不能将合并平均提升当作稳定优势。弱疲劳下常不改变选择，只增加费用。

连续最微小探针的均衡排序相关性达到1，但平均接受收益仅0.0000221%，决策代理约8.06ms；time_only约7.46ms且选择已很接近，单次收益率反而更高。准确的敏感性工具不自动等于划算的搜索引导，更不能把改变ST的探针收益当作真实可优化收益。

## 哪些条件出现了值得继续验证的信号

1. **导数用途：**绑定/依赖图和活跃分支稳定、变化幅度小，且需要计入疲劳传递时，完整伴随明显比时间通道准确；本轮对此有直接证据。对合法编辑，不能仅凭“只改一个位置”判定物理扰动小。
2. **候选选择用途：**局部编码编辑比大范围换序更合适，但还应处理首阶段近似。本轮没有实现在线稳定性门控，也没有将诊断用真实首阶段重算作为新选择器部署。
3. **成本用途：**同一父本不变时，批量池可摊薄一次trace/伴随费用。只有在父本未更新时q=4/16才成立；接受新父本后缓存失效，真实搜索能复用多少次尚未测量。
4. **疲劳强度和目标方向：**少数条件出现正信号。例如强疲劳快恢复、局部池、TEC方向、q=4的完整伴随单位代理时间收益为0.2411%/ms，时间通道0.1969%/ms，随机0.0942%/ms；相对时间通道的配对差为+0.0442%/ms，描述区间[+0.0018,+0.1306]，相对随机也为正。q=16同方向仍有正信号。

最后一点来自许多相关对照中的少数条件，只是下一轮假设，不是经过多重比较的确认性结论。较大池强疲劳快恢复、均衡方向在q>=4时虽相对时间通道有正区间，相对随机仍跨0，不能据此说大范围编辑值得使用完整伴随。

当前最有依据的判断是：保留完整疲劳反向作为可靠敏感性工具，优先检验局部合法编辑、首阶段准确性及可复用成本；避免把它直接当作任意离散换序的通用预测器。下一步若继续，应先独立验证这些特定条件和实际可获得的稳定性指标，再决定是否接入优化器。

## 适用边界

所有结论只针对当前合成疲劳、公开重建SUT/standby、随机合法父本和最早开工append-only解码。没有主动休息/插空/右移，未作人体实测校准；六个实例簇不足以确立总体算法优势。时间来自Python通用实现，time_only尚未专门优化为轻量关键路径，候选生成本身也较贵。未进行等FE/等时间优化器、Pareto/HV/IGD+或发表级性能验证。

v1的探索性存档分层单独保存为 `v1_exploratory_strata.json`：后阶段图不变的114候选误差较小，但仍明显非零。它没有新增解码、不覆盖v1、不当作本轮新seed证据。
