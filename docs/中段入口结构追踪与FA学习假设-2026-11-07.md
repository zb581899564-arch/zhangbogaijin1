# 中段入口结构如何形成和丢失：已付费轨迹分析

2026-11-07。**中段问题更接近“已有结构如何被下一轮使用和重新组织”，目前仍未识别唯一根因。** 代末没有普遍删掉优秀局搜出口，QGS也实际读取了它们；完整排程的减少主要发生在下一轮QGS。逐工件资源和大量两工件顺序片段仍然存在。下一项建议只隔离链接模型中的FA统计来源，先讨论，不运行新评价。

## 范围、物理身份及费用

实例100_2_3_1、原seed14910003，只读此前已验收的SHARE完整pipeline、Linux500k付费CSV、PA250k完整模型入口，以及上一轮资源反事实的冻结资料。所有数学与源身份核对在Linux执行；新增搜索FE、动态解码、QA、目标查询和候选构造均为0。重建链接模型有CPU成本，不称零计算成本。

完整观察第5—10轮，覆盖QGS出口104540至228840、局搜出口124400至248700。第5轮QGS从99540开始，包含窗口左侧460次；第11轮在248700开始、至250000有1300次已付费QGS/共享提议，但没有完整阶段出口，单列而不伪造250k工作种群。跨轮追踪以第4—9轮局搜出口为出生状态，再看第5—10轮；第4轮出口99540仅作为左边界已付费入口。

物理身份为每厂有序(job,machine,worker)链，忽略跨厂全局交错。另分别跟踪整份FA、逐job完整FMW、同厂两个job的有向先后关系及各自FMW。片段在不同成员中存在，不保证可以一次组合成完整排程。

同一条轨迹的六轮属于相关观测，不能当六个独立seed。状态数量明确区分出现记录和去重后的物理状态。

## 1. 结构确实在局搜形成，也确实传入下一轮

对每个出生轮，只登记“局搜出口在全局出口中没有相同物理排程，且其目标不被当轮200候选池严格支配”的状态。不是根据以后能否获胜来选点，也不是全部中间局搜发现的集合。

312条对应309个不同物理排程。312条都被下一轮QGS实际用作当前父代，其中143条被用作个人教师、151条被用作全局教师，二者可能重叠。296条在下一轮全局出口的内部档案仍有精确key；其余不能据此宣称所有物理别名/个人历史都消失。

因此，不支持“局搜成果根本没有接入下一轮”或“只要放进生存池即可修好”的解释。全部已付费解始终还在共同外部结果档案口径中，工作态减少不等于结果档案HV被删除。

QGS结束后，122条不再以完整排程存在于当前100人中。它们的逐job资源片段保留比例中位数为100%，带完整FMW的同厂有向job对保留比例中位数为95.8044%。有部分结构被拆散，但不能把完整key消失称为信息完全丢失。按出生职责，工期/中央/能耗/成本的记录分别24/236/27/25，失去完整工作态分别14/78/18/12；职责数量不同，不能直接按丢失个数确定哪群受损最严重或分配新配额。

## 2. 质量、组合结构与单字段支持必须分开

六个完整轮的描述性中位，质量使用同一旧经验参考、冻结尺度和精确ND目标集。IGD+列为对称改善，正为好；C相等计覆盖，两个方向不互补。

| 更新 | 当前群体HV变化 | IGD+改善 | C(后,前) / C(前,后) |
|---|---:|---:|---:|
| QGS前→后 | −0.117711% | −5.827521% | 63.2707% / 75.1913% |
| 全局出口→局搜出口 | +0.978788% | +12.152334% | 63.8028% / 3.3077% |
| 200池→100生存者 | 0 | 0 | 100% / 100% |

最后一轮生存选择有小损失：HV−0.00915%、IGD+改善−0.1851%；其余五轮的池前沿全部保留。局搜六轮均在三指标方向上提高全局出口群体质量。QGS六轮当前群体HV/IGD+均下降，但QGS自身有已付费新发现，不能把这张表当成关闭全局搜索的因果证明。

自由80的整份FA组合在QGS前为66、69、67、62、67、64种，QGS后为45、45、45、45、44、46种。同期逐job FMW支持的保留率中位98.3506%，有向job/FMW对为91.6913%。这与上一轮“补入更多资源仍很少增加共同前沿容量”的结果相容：不是简单缺几个可选元组，而是组合结构和后续组织方式可能不同。

PA同期模型入口有96—100份不同FA、相同FA最多出现两次；SHARE全局出口同一FA最多出现11次。两者的模型训练域也不同（100自由与80自由＋20固定），这里只报告关联，不从这些自然轨迹差异推导扩池、取消家族或去重加权必然有效。

## 3. 一个尚未单独测试的通道：FA统计如何改变FOS

原free80链接矩阵同时使用FA共分配的二项尾部强度/吸引或排斥分支、FA互信息，以及同厂顺序项。虽然前后FA共分配频率向量相关系数仍为0.973—0.994，统计映射和层次合并会使小的分布变化形成不同掩码。相关性高不等于实际联合修改结构相同。

本轮只做代数反事实：保留真实POST_GLOBAL的重编码键和顺序内部项，用PRE_GLOBAL自由80的FA统计替代POST_GLOBAL FA统计；权重、80样本、3厂、层次聚类和固定家族模型都不变。FA统计包含吸引/排斥分支、尾部强度和外部互信息，不能把它误写成只换一个乘数。没有生成或评分候选。

| 轮 / 全局出口FE | 原98个非平凡FOS块中改变数 | 链接矩阵平均绝对变化 |
|---|---:|---:|
| 5 / 104540 | 69 | 0.053471 |
| 6 / 129400 | 77 | 0.081306 |
| 7 / 154260 | 52 | 0.075787 |
| 8 / 179120 | 53 | 0.041517 |
| 9 / 203980 | 71 | 0.071869 |
| 10 / 228840 | 47 | 0.041173 |

单工件叶子和全工件根不计入98块。三个旧采样入口的原POST矩阵/FOS与上一轮重建逐项一致；六个反事实矩阵经独立熵/二项分布计算，原模型和反事实层次合并均逐次验证，最大矩阵误差3.33e−16。

这证明统计来源能够实质改变联合分组，**没有证明QGS后的分组是坏的，也没有证明QGS前的分组更好**。这正是下一项应单独验证的因素。

## 4. 与旧失败的区别

| 旧方案 | 曾改变什么 | 新假设固定什么，只改变什么 |
|---|---|---|
| PRE_FIRST | 局搜改从QGS前父代出发，供体和模型输入随之改变 | 保留QGS后父代、供体、实际顺序键及接受，只换链接模型中的FA统计来源 |
| GLOBAL/LOCAL职责2×2 | 第10轮改变全局或局部目标偏好 | 四职责、QGS动作/Q参数、原共享及群体选择全部固定 |
| ALL/OWN/SYNC | 已完成新供体的可见时机 | 保持原live供体和即时接受，不改变状态发布 |
| R/G/S/UNION与最新PA资源试验 | 供体内容、支持域或来源 | 不引入PA供体、不扩池、不改资源/顺序内容 |
| 家族刷新、字段解绑 | 合法域、家族配置或生成方式 | 固定20家族的模型、域和配额；只测试自由80的统计通道 |
| 保留/后筛选 | 工作种群或教师的选择 | 使用同一批已付费接收者和供体，原生存及档案规则保留 |

PRE_FIRST在100例短预算有收益、20例退化的事实保留，不把它改轮次重新启动。新问题是其中的“模型通道”是否独立有价值，而不是恢复这个已经停止的整包架构。过去不能按不同框架的正组件把收益直接相加，本次也同样。

## 5. 验收、证据与状态

独立检查3200份旧pipeline与Linux当前快照的key、目标、family和阶段FE；选择索引与下一入口物理多重集一致。312条合格出口的非支配身份、跨轮成员和QGS教师使用由另一个脚本重建。24次HV和24次IGD+独立复算最大绝对误差分别3.33e−16和1.39e−17；六组模型数学和层次合并通过。没有新性能轨迹。

原分析器初版把phase写成通用global，实际标签为QGS/SHARED，导致使用计数为空；v2按真实标签重算并核对每完整轮5000次。第一次独立验收又把第11轮1300次部分前缀算进完整轮断言而停止，v2单列该部分后通过。两个问题都发生在0新FE/0解码的分析中，原代码、输出和失败日志保留；有效结果为analysis-v2与independent-audit.json。

完整证据：[本轮目录](../runs/linux-mid-history-20261107-01/linux-results/)。数据计算只在Linux执行，统计参考与源hash见protocol.json和analysis-v2/acceptance.json；这是相关轨迹诊断，不是新seed或性能证明。
