# 基线语义修复与210次同期验证结果

日期：2026-11-02。已按[执行计划v1](基线语义修复执行计划-v1-2026-11-02.md)完成S/O实现、针对性验收、两批210次完整运行和已付费池离线诊断。旧材料、v2二进制、旧270次及其判定均保留。没有新学习器、调参、目标切换或正式第6步扩量。

**主要结果：语义修复没有带来总体性能提升；共享在修正基线上仍有独立增量；当前完整配置仍落后NSGA-II。** 因此需要修正上一轮的优先怀疑：100选100是有原文依据的重建缺口，但本轮不支持把它作为主要性能差距的解释，更不能保证“恢复精英池就能追平”。

## 4. S/O修复带来多少变化

主HV参考点1.5。先平均同实例五seed，再比较六实例。实质胜须实例提升≥1%且至少3/5配对seed为正；它不是统计显著性。

|比较|平均HV变化|中位数|实质胜/负|
|---|---:|---:|---|
|S_ONLY / V2|−0.169%|+0.100%|0/1|
|O_ONLY / V2|−2.654%|−2.096%|0/6|
|SO / V2|−1.940%|−1.656%|0/4|

在15000FE，S_ONLY/V2平均−0.493%、O_ONLY/V2−2.006%、SO/V2−1.855%，与“单纯额外耗时拖累”的解释不符。参考点1.25/2.0下，SO/V2平均分别−2.913%/−1.190%，O_ONLY/V2−3.928%/−1.643%，负方向没有靠换参考点消失。

应继续保留这些语义修复并诚实命名，不能因为性能没提高而偷偷换回有利旧操作、再称已复现原论文；后续替换生成或选择规则属于算法变体。

## 7. 生成—保留—传播诊断

### 保留：没有看到大量优质ND记录被截断直接丢掉

630个截止有效候选池均完成重放。S_ONLY、SO、SYNC_FIX捕获池的非支配记录数最多分别41、43、40条，低于容量100；各自捕获池的全部ND目标均被幸存者覆盖、全池HV损失为0。

保持同容量、同合作配额换成rank+crowding，S_ONLY/SO/SYNC_FIX平均瞬时HV变化为0，SHARE_FIX仅+0.016%。SHARE_FIX原选择相对全池平均损失约0.016%，个别池最高1.436%；移除配额、仍用PDDR的同池均值改善约0.016%。这是探索性补充，不是新主判据，也不是闭环选择器效果。

PDDR理论上可能在全ND池大量并列，但本批截断边界平均并列记录较少，没有实际支持“严重并列导致前沿大面积丢失”作为主要解释。不能反过来宣布选择器永远无关：其对被保留的支配解、后续父本分布和长期轨迹仍可能有影响。

SO末期捕获池的幸存者平均约99.5种工厂局部编码，记录的更新链根身份约24.6个；v2为100个根身份。这说明双分支竞争产生了更新链谱系集中，不能说当前编码都变成克隆，也不等于真实遗传祖先数：该lineage只追踪粒子更新链，不追踪从pbest/gbest引入的全部基因贡献。

### 传播：共享成果进入过实际搜索路径

SHARE_FIX的18,788个直接组合来源全部被追踪且完成付费，未达到4096/运行的上限。2,751个曾进入截止有效外部档案，673个曾成为代末幸存粒子，3,384个曾被选为教师，其中3,380个被后续更新核实际读取。

这些不是必须依次嵌套的漏斗：个人历史可在代末之前就使用共享来源。teacherConsumed也只表示实际读取，不表示一定改变子代或带来后代质量收益。改变后的编码不归为原共享基因型，不做未验证的后代因果归因。

共享组合约占该方法全局成功FE的1.671%，贡献了约20.212%的全局外部档案接纳事件；共享来源自身的曾入档率14.642%。这支持保留精确共享作为有效候选来源，但不是最终HV的20.212%贡献，也不证明所有实例共享都划算。

### 生成与闭环搜索：下一优先问题，但未完成固有算子因果拆分

修复后全局候选抽样不同率约99.9%，不是大量原样重复；NSGA-II约99.5%。不同编码不等于高质量候选。所有阶段付费候选的曾入档比例约SO 1.380%、NSGA-II 3.223%，反映这两个闭环轨迹发现新档案解的效率不同；它们的父本与阶段分配已不同，不能据此证明NSGA生成核固有更强。

综合S/O、同FE和同池结果，当前证据优先指向全局更新/引导与搜索轨迹，而非解码太慢、简单丢掉大量好前沿、或共享反馈完全没接通。下一项最小机制验证应从同一批固定父本/pbest/gbest快照出发，检查位置更新与按job保留资源结构的差异；继续保留四群与共享，不立即增加Q层或整套重调参数。本轮没有执行该新假设。
