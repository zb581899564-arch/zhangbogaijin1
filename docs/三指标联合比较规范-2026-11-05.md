# HV、IGD+与双向C的联合比较口径

2026-11-05，依据用户明确要求生效：后续算法表现、消融和推进判断必须综合HV、IGD+、双向C，不再用HV一项概括优劣。本文件规定报告与解释方式，不设一个新的“贡献审查”，不修改算法的优化目标、内部接受或共享规则。

## 指标各回答什么

|指标|方向|解释与限制|
|---|---|---|
|HV|越大越好|固定归一化和参考点下的支配体积；同时给出事前登记的参考点敏感性。|
|IGD+|越小越好|与共同参考前沿的距离；没有真前沿时是经验近似，必须公开参考构造。|
|C(A,B)、C(B,A)|对A而言前者高、后者低较有利|分别表示对方集合被己方弱支配的比例；两个方向均须报告。覆盖率还受点分布和集合大小影响，不是全部质量的总排序。|

本项目三目标均为最小化。设A、B为按原始目标向量精确去重的非空前沿：

\[
C(A,B)=\frac{|\{b\in B:\exists a\in A,\ \forall k,\ a_k\le b_k\}|}{|B|}.
\]

相等目标向量计入覆盖；两个方向不互补。相同前沿可为1/1，互不覆盖可为0/0；后一种情形只能说C无法区分，不能伪称双方同样接近最优。报告中明确比例或百分数，并保留覆盖点数、分母、相同目标点数及前沿大小。缺失/空前沿列为未完成或无效，不虚构C值。C默认使用原始双精度目标、精确`<=`，不在看到结果后增设epsilon。

定义和双向报告依据为[Zitzler (1999), Definition 9](https://sop.tik.ee.ethz.ch/publicationListFiles/zitz1999a.pdf)。本项目沿用已有`research/expansion_audit/metrics.py::coverage`，补充集合去重、输入检查和覆盖计数；不将严格支配版本混作同一指标。

## 一起看，怎样形成判断

每个事前指定的实例、预算点和对照，先列逐seed的HV、IGD+、C两个方向，再列配对效应和实例内汇总。HV和IGD+都报告原始值；仅给相对百分比可能掩盖零附近数值。当前IGD+效应沿用`200*(IA-IB)/(IA+IB)`，两者同为0取0，正数为恶化；名称为“对称恶化百分比”，不能写成传统相对对手百分比。

- 三项可辨别方向一致，且达到事前登记的实质幅度与稳健性要求，才表述为该预算下的综合优势。
- 指标冲突，明确报告权衡和退化发生在哪个指标、实例或seed；不能仅凭HV更高宣布整体获胜，也不能用“三项中赢两项”投票掩盖第三项的实质恶化。
- 某项几乎无差异或无辨别力，标明证据有限。C为0/0或1/1不强行要求它出现严格获胜；同时防止把微小数值差异写成实质收益。
- 同FE和同时间分别完成这张联合对照，保留未达到公共预算点、失败、最差实例和全部成本。物理三目标极值用于解释前沿，不将来自不同解的极值拼成一个“最佳调度”。

不规定任意加权总分；HV、IGD+、C也不是三个独立显著性检验投票。正式统计以实例为比较单位，seed是实例内重复；小诊断只报告描述性证据。

## 如何影响后续实验与既有结果

新实验在运行前冻结三个指标的计算方式、原始值与效应报告、实质改善/不劣界限、参考前沿、覆盖方向，以及分歧时如何处理。新推进协议须显式纳入三指标，不得只在报告末尾附一项C而仍以HV独断，也不默认必须三项每次都严格获胜。具体幅度按研究问题与可用成本另行登记，本文件不凭已有结果反推新阈值。

已经冻结的协议、原始数值和停止决定保留；对旧实验可追加有明确日期的三指标补充解释，不能回写旧gate或据此追认“已通过”。现有500k记录的补充是离线再分析，不是新的独立确认。最终算法仍需保留四职责、已有共享的独立检验，以及原共享/Li规范重建和强经典对照。
