# 第四、第五步结果：完整算法与四子群共享初筛

第四、第五步均已完成。**当前最值得进一步确认的是固定FA家族内的整厂共享组合；学习型余程VALUE尚未建立相对强控制的独立同时间优势，也未显示与共享的正向交互。** 这不是对四子群框架的否定，而是对本轮具体生成器、共享规则和预算的判断。

本轮仅为开发初筛，尚未完成第六步独立确认，不能据此声称已达到ESWA论文证据要求。

## 1. 实际完成的工作

- 第四步五版本：BASELINE、RANDOM、GREEDY、TAIL、VALUE，300次完整运行。
- 第五步增加SYNC、VALUE_SYNC、SHARE、VALUE_SHARE，240次；复用同协议BASELINE/VALUE，完成2×2及必要FA同步控制。
- 共6个合格开发实例×5个新seed×9版本×2预算=540次独立JVM运行。实例为20_2_3_1、20_8_5_1、100_2_3_1、100_8_3_1、200_5_3_1、200_8_5_1。
- 同FE均为30000；同时间分别为3/4/5/9/12/19秒。默认100粒子、边界各15、综合55、Qg=50、原普通局部搜索；Cmax/TEC/TWC不变。

完整规则见[冻结协议](第四五步实验协议-2026-11-01.md)，组合成立条件见[性质与边界](整厂共享组合的性质与边界.md)。主证据位于`runs/dynamic-step45-20261101-192250-613958/`。

## 2. 第四步：联合构造和价值学习分别带来什么

下表的百分比为先在每个实例平均5seed，再计算相对HV变化，最后平均6实例；不是把所有seed当独立实例。括号为实例胜数/6。主HV参考点事前固定为(1.1,1.1,1.1)。

|比较|同FE平均相对HV|同时间平均相对HV|可支持的判断|
|---|---:|---:|---|
|VALUE / BASELINE|+2.50%（5/6）|−0.96%（3/6）|有同FE信号，尚未转为稳定同时间收益|
|VALUE / RANDOM|+6.75%（6/6）|+5.56%（6/6）|有指导比随机合法构造好，但随机是较弱控制|
|VALUE / TAIL|−1.16%（2/6）|−1.32%（2/6）|未建立学习相对非学习尾程的增量|
|RANDOM / BASELINE|−3.96%（0/6）|−6.15%（0/6）|当前联合候选规则配随机选择本身没有收益|

VALUE相对GREEDY的平均绝对HV差在同FE和同时间分别为−0.000393、−0.000524，均仅赢2/6实例。该对照的平均相对百分比与绝对差异号，源于各实例分母和尺度不同；不能只取一个有利平均数。

IGD+也未支持VALUE的同时间独立优势：相对BASELINE，六实例全部更差；相对TAIL，仅1/6更好。参考集是事前约定的九版本共同经验前沿，属于近似参考，不是真Pareto前沿。

因此目前可以说：**该版本的学习指导优于随机，但没有优于最强普通评分控制的可靠同时间证据。** 不能把“胜随机”直接写成主创新有效，也不能由这个结果推断所有价值学习路线无效。

SYNC与SHARE采用相同FA家族、资源重绑定、分群配额；SYNC关闭方案池和组合。VALUE_SYNC与VALUE_SHARE同理。以下对照由此分开家族约束和组合的作用。

## 4. 没有观察到正向交互

事前定义交互为：

\[
(HV_{VALUE\_SHARE}-HV_{SHARE})-(HV_{VALUE}-HV_{BASELINE}).
\]

|预算|平均交互HV差|实例正/负|95%探索性bootstrap区间|
|---|---:|---:|---|
|同FE|−0.000965|2/4|[−0.002500, +0.000231]|
|同时间|−0.000534|3/3|[−0.001847, +0.000631]|

当前证据不能支持“VALUE与共享相互增强”。VALUE_SHARE在同FE下相对SHARE六例均有小幅提升，但计入时间后有四例退化，IGD+仅1/6更好。它相对VALUE单用的提升，也不能反过来证明学习的条件性贡献——这里SHARE单用已取得更强同时间表现。

这不证明确定存在负协同；六实例交互区间跨零。能够明确的是：**本轮不能把正向协同写为已验证贡献。**

## 6. 参考点与统计边界

主指标没有改：归一化来自正式运行前128个独立随机父本，参考点固定1.1。末期有效档案中有1541个点在该参考盒之外，均来自200_8_5_1，占该实例15997点约9.6%；这些点保留在原始前沿和IGD+中，HV对参考盒外体积不计分。

因此追加了明确标注为**事后敏感性分析**的1.25、1.5参考点核对，没有新搜索，没有据此改主点、模型或主检验。主要TIME结果为：

收益幅度对参考点敏感，“SHARE相对SYNC六实例全胜”也不能推广到所有参考点；但共享相对基线的总体正方向、两例退化，以及当前VALUE缺乏独立同时间优势的判断均未被逆转。敏感性分析不能替代独立确认。

统计按6个实例配对，5seed只是实例内重复。报告保留原始差、胜负、5000次bootstrap、精确单侧符号翻转及Holm校正。由于N=6的最小p为1/64，10/12项校正不可能达到.05，本轮没有以显著性硬门槛作准入；区间和方向同样只作开发证据，不解释为“未显著所以无效”。

六实例均为开发资料，只有一个合成疲劳场景；尚未验证β=0、其他疲劳强度、独立实例、长预算及近期强方法。固定FA家族不刷新也构成探索限制。桌面背景负载没有严格控制，正式时间结论还需重复确认。

## 8. 下一步建议及本轮停止范围

更值得带入第六步确认的是SHARE，TAIL/GREEDY继续作为强内部控制，VALUE和VALUE_SHARE保留为当前实现的消融。首先确认共享收益是否能跨独立实例、疲劳场景和长预算保持，特别关注20_8_5_1与200_5_3_1两例退化，以及100_2_3_1对均值的贡献。

这不是在本轮直接重排论文贡献或宣判学习路线失败。对VALUE若再推进，需要一个由现有轨迹/费用支持、单独冻结的新假设；不能因本轮不理想就无限调块长、调用比例、学习率或seed。第六步的正式比较、疲劳信息消融与近邻方法差异确认另立协议后实施，本轮未自动启动。
