# v10：固定普通混合的规模与预算泛化

日期：2026-11-01。**实验和审计已完成，但未建立固定混合相对普通复合单用的规模优势。** 混合优于受限的交换重绑定，不足以成为独立方法贡献；不从20工件分层的正结果事后选阈值或调比例。

证据：[冻结协议](规模泛化协议-v10.md)、[完整结果表](../runs/fatigue-scale-performance-v10-20261101-003849-681912/report.md)、[全部模式与分层汇总](../runs/fatigue-scale-performance-v10-20261101-003849-681912/summary.json)、[审计](../runs/fatigue-scale-performance-v10-20261101-003849-681912/audit.json)。

## 1. 实际完成的范围

全部36个第四章资源条件合格实例，N=20/50/100/150/200、3—5工厂、2/5/8阶段，3个新父本seed；beta0、强快和强慢TEC均运行65FE及0.5/2秒，强快均衡方向另作0.5秒补充。共108个匹配父本、4320条局部链。四方法为普通复合、交换重绑定、固定50%随机、严格交替，无评分器、自适应或参数搜索。每固定FE链1父本+64子本，交替32+32。

输入和疲劳生成规则沿用v5冻结映射，SUT/standby为明确重建、疲劳参数为合成场景。它们是原材料数值上的共同动态解码研究，不是作者原成绩复现。即使beta0也不能把本表与Java插空/右移基线成绩直接相减。共享物理核心和整套算法未改。

为推广v9，新增一般资源State和rank抽样：任意工厂数/资源数、按合法N1数量均匀抽样、跨厂job对均匀选择、新厂合法资源重绑定。没有枚举巨大候选列表来拖慢普通对照；相同微例完整N1支持集和交换支持集与旧实现桥接一致。

## 2. 主结果：强快TEC

数值为相对初始父本的平均改善百分数，先在每实例内平均3父本，再按36实例比较。

|预算|普通复合|交换重绑定|随机50%混合|严格交替|
|---|---|---|---|---|
|65FE|8.5035%|6.3915%|8.1846%|8.1751%|
|0.5秒|11.8651%|9.1081%|11.7866%|11.8906%|
|2秒|15.8613%|11.8664%|15.7445%|15.7161%|

主比较为两混合各对两个单用×3预算，共12项，使用冻结的层次实例→父本bootstrap95区间与单侧sign-flip、12项Holm校正。全部区间是未调整的效应区间，Holm仅作用p值。

|预算|混合−普通：随机/交替（pp）|95%区间：随机/交替|实例胜平负：随机/交替|
|---|---|---|---|
|65FE|-0.3189 / -0.3284|[-0.7985,0.1987] / [-0.8369,0.1752]|15/0/21；16/0/20|
|0.5秒|-0.0786 / +0.0255|[-0.6636,0.4896] / [-0.5404,0.5625]|19/0/17；20/0/16|
|2秒|-0.1169 / -0.1452|[-0.7477,0.4924] / [-0.8909,0.5441]|21/0/15；17/0/19|

六项混合对普通复合的Holm p均为1，区间均跨0，不能宣称优于普通复合，也不能由“不显著”证明二者等效或混合必然更差。五个点估计为负，一个只有+0.0255pp。相反，六项混合对交换重绑定的差为+1.78到+3.88pp，区间均为正、Holm p≤0.00021；这是加回广覆盖普通复合后优于受限交换控制，不能拿它替代更强的普通对照。

按工件数的预定描述分层，强快TEC下混合对普通复合的均值差：

|---|---|---|---|
|20|9|+1.8280 / +1.8240|+1.4822 / +1.7790|
|50|8|-1.0892 / -0.4657|-0.4972 / -0.9459|

工件数层还混有不同资源/阶段配置，不能将上表当作规模的单因素因果效应，也不据此设计“N=20才混合”的事后门槛。v9微例正信号没有推广为一般优势。

beta0中普通复合三个预算均值都高于两混合。强慢中混合在0.5/2秒略有正负交错，65FE低于普通；强快均衡0.5秒交替比普通高约0.12pp、随机高约0.22pp。这些是控制/探索单元，不换主目标，不作为疲劳反向信息收益：本轮四个策略都不使用疲劳评分。

实际gain/sec与截止前gain方向一致：主单元普通/随机/交替在0.5秒分别0.23675/0.23519/0.23732，2秒0.07925/0.07867/0.07853（归一化改善/秒，含尾步超时）。性能差不是靠隐藏较长尾步取得。

## 4. 一般多厂支持边界与noop

[支持集边界说明](规模泛化支持集边界-v10.md)在计时结束前已登记，不修改主统计。v9子集结论只适用于其F=2、N=3/4空间；一般多厂若被交换两厂各一job，原子交换合法，而两次逐步非空N1无法完成同一交换。最小结构证书N=F=3、每厂2机2工，27个不同N2终点都保持FA，原子交换改变FA且非空。不是新物理模型，也不构成新颖性：原论文已有原子厂间交换。

事后仅重放已记录FA变化、核对最终厂别与数量，0新增解码调用。结果见[boundary_review.json](../runs/fatigue-scale-performance-v10-20261101-003849-681912/boundary_review.json)：

- 所有初始父本均未有两个单job厂；搜索中共469次“两被交换厂皆单job”的原子提案、17次接收，**全部在beta0控制里**。
- 强快TEC主单元和强慢/均衡没有触发该原子单job交换，不能用反例解释主单元的混合收益/退化。
- 2217044个plain分量中4468个无合法N1（约0.2015%），全部明确为计费noop分量；最终完整子本只有4个完全不变。没有无上限免费重抽，也不能将分量noop与完整noop混为同一分母。
