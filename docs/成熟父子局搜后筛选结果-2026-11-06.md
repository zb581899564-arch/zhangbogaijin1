# 成熟父子局搜后筛选：三臂同费用结果

**结论：停止本轮固定 POST_ROLE 分支，不扩量，不按新 seed、窗口或局搜长度追正。** 工程正确性通过；后筛选确实改变了保留对象，但主终点没有实质收益，100例 IGD+ 和双向 C 有明确退化。普通 POST_PARETO 也没有解决同预算问题。原四职责、QGS、固定 FA 家族和已有共享收益继续保留，生产默认主线未改，Goal 未恢复。

本轮执行对应[当前创新主张与冻结方案](当前创新主张与局搜后筛选验证协议-2026-11-06.md)。它检验成熟状态中的一批完整候选，经局搜后再筛选是否值得花费；不把四子群形式、普通模因搜索顺序或工程提速本身称为新发明。

## 机制解释及旧失败的区别

P与R选中根身份的重合数为20例63/81/65、100例85/79/82（各100人）；不是机制未触发。P通常保留更多C来源，但根身份不是改善后的完整状态，不能把来源变化直接解释为质量贡献。

20例最终工作种群 P/R 的HV、IGD+中位为 +0.153641%、+3.868280%，但公共末档案未获得收益；100例工作种群为 −0.168365%、−4.973991%。两POST在2B时的公共档案完全一致；100例当时相对R的HV、IGD+为 −0.196579%、−9.514204%，最后一轮缩小了部分差距，却未形成合格主终点。

这与只选旧父代的PRE_FIRST、扩展R/G/S供体材料、改变即时职责偏好、代末保留G+L的实验不同。新增证据否定的是**该成熟背景、首批候选及三轮预算下，这种后筛选安排值得继续**。它未证明所有全局候选都无价值，也未证明所有后筛选方案无效。现有证据不支持通过调供体比例、扩大池或简单延后筛选解决完整算法差距。

P相对普通U在20例三指标全部不利，100例IGD+和C也不利，故本轮没有新增“角色化后筛选”的独特收益。局搜和原四职责/共享已有正证据不受此结论替代；尤其S=0使本轮无权判断直接共享提议。
