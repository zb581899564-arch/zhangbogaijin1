# 小试评价与 Linux 阶段诊断协议

本协议落实用户批准的“小试驱动的评价、机制取舍与持续迭代方案”。原四职责及已有共享收益优先保留；以证据决定是否删去复杂度。工程验收、机制局部价值和完整算法竞争力分别判断。已清除的 Goal 不恢复，不安装后台实验服务。

## 本轮边界

研究锚点为 `ctx-gom-capability-20261106-051509-678987` 的完整 `SHARE_CTX_GOM` 冻结版本。它有相对旧共享的正证据，但此前完整竞争力未过关；本轮不推翻旧停止、不晋升默认主线。三臂为 FULL、GLOBAL_ONLY、LOCAL_ONLY；同实例、同 seed 的100个初始四向量及目标必须一致。

开发实例固定为 `20_8_5_1`、`100_2_3_1`；新 seed 固定为 `16110003、16110037、16110069`。每臂50万实际 FE，18条，共900万科学 FE。工程与离线解码另计。按实例、seed 顺序轮转三臂，单 JVM 顺序执行；不在批次中途根据质量替换 seed、预算、终点或方法。

关闭全局时，不调用 QGS、引导选择、全局生成及其 RNG；保留分群、家族、共享池更新、个人历史和生存生命周期。原共享组装仅在全局调用，因此 LOCAL_ONLY **没有共享组装请求**，不能称为“组装保持不变”的纯局搜因果对照。

关闭局搜时，连入口重编码、模型构建和 RNG 一并跳过。原生存器处理100个全局快照，不能再添加100个重复 offspring。LOCAL_ONLY 与 FULL 保留原100+100候选生存语义。两个开关比较的是固定总预算的替代机会，差值不解释为某阶段独立贡献百分比。

## 平台与迁移

Windows 只开发、传输、提交和查看。全部搜索、解码检查、统计和绘图在 Linux 项目独立目录执行，使用已有 `aic-inspur-home`，保留指纹校验，无 Mac 中转或网络配置改动。SSH 可用不等于完整 DIRECT 路径已证实。

运行环境为 JDK17、Java8编译目标、Python3.11。冻结原 classpath 顺序，保留各原类和依赖字节；隔离覆盖只包含阶段门控和只读观察。记录实际加载类、源文件、输入、依赖版本和运行前后外部负载。Windows 历史前沿可用于一致性核对，耗时不加入 Linux 排名。

工程门包括：原冻结版与 FULL 整条付费序列一致、观察开关轨迹一致、100初始解一致、阶段计费和家族配额、1/2/最后一次 FE、全局及局部中途截止、真实失败计费和最后有效前沿、全解码与精确增量完整时间轴一致。数学夹具独立核对 HV、IGD/IGD+方向、精确C、EAF及阶段增量加总。任何异常保留证据并停在工程层，不换 seed 补结果。

## 评价与归因

机器可读规则见 `research/pilot_evaluation/evaluation_contract_v3.json`。仍用 Cmax、TEC、TWC，全部最小化；原实例尺度固定。HV主参考点1.5，敏感性1.25、2.0。IGD+与传统IGD使用本批全部末前沿的统一非支配并集，离线评分所有检查点，不反馈搜索。C精确弱支配、相等计覆盖，两个方向附数量和分母。

保存初始化和1万、5万、10万、25万、50万 FE 前沿及阶段边界。50万是主终点。每个目标的极值保留对应完整三向量；所有seed逐条报告，再给实例内配对中位数、范围和改善次数。不加权投票，不把3个seed称为统计确认。

本轮3个seed展示逐次前沿、三维散点和二维投影，不生成50%达成面。补到5个seed时才显示达成面，并按共同参考集预定四分位数作第三目标条件切片。投影不能替代三目标支配判断。

逐次记录真实 FE、阶段、物理职责、直接生成来源、档案准入和耗时，结束后才算指标。初始 HV 加全局与局搜的直接 HV 增量应等于最终 HV；共享是全局内部来源，不能重复加总。阶段效率同时给实际 FE 与完整搜索耗时，观察和离线 QA 单列，不把观察时间简单扣掉后称作实测速度。

工作态记录区分：局部候选即时接受、已完成阶段出口、实际下一轮入口和末前沿留存。没有逐个全局 QGS 批次快照，因此阶段出口未出现的点不能推断为“从未进入工作态”；中途截止没有出口时标缺失。外部档案单调改善不等于工作种群改善。

## 后续取舍

普通机制轮用两例、三seed、候选与直接消融各50万，共600万 FE。实质信号默认取实例内配对中位 HV≥1% 或 IGD+对称改善≥5%，且对应实例至少两个seed改善；另一实例重大退化及C反向超过10个百分点必须解释。不能凭HV单独绿灯，也不能只凭C一个数断言整条前沿退化。

无实质质量或成本价值时停止固定机制；证据不足最多补两个预登记seed，不改算法追正。质量相当且成本下降至少10%可作为效率候选，仍须真实 TIME_LIMIT。第二级才补五seed与一份预选验证实例，按问题加入普通及匹配增强 NSGA-II、PA、旧共享和 Li 规范重建，公开强控制反证。真实时间预算由事前指定 Linux 匹配 NSGA-II 的50万 FE耗时中位数冻结。

先完成本轮完整诊断，再登记一个新假设，写清证据缺口、改动、与旧失败机制的区别及可推翻它的普通对照。每三个新假设做一次收敛。本轮通过不等于论文级泛化或保证探索到优胜算法。
