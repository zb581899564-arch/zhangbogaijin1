# 跨职责动作反馈小验证（2026-11-05）

**本固定反馈模型停止，不接入完整算法。** 相对本群数据虽有单步收益，但没有胜过普通的职责动作均值；等量跨群数据和疲劳特征也没有跨两例的独立收益。换奖励目标、特征、回归参数、数据窗口或seed来救此版本均不执行。

## 要回答的问题与原方案边界

原《四子群协作信用强化学习_研究设计》是候选资料，其中的第三目标R、池留一价值、宏动作和Q替换没有自动成为当前实验要求。本项仍用Cmax/TEC/TWC、原四职责和共同动态模型。已停止的池容量/共享选择、整解接力和联合算子不重开。

新问题是：同一付费候选已经产生三个目标变化，是否可由不同职责共同学习动作效果，比各自学习、普通状态无关均值和随机动作更有效？这里的“重用”仅指**已执行动作在同一父代的三目标反馈**，不能推导未执行动作或继续搜索的反事实结果。

## 事前协议和工程

[冻结协议](../runs/action-feedback-probe-20261105-094303-818797/protocol.json)先于结果。来源为既有mating-pool-probe的全部六个真实中央批次入口窗口，source seed11730007/11730037，每个职责按位置等距取8个自由父代，每实例192个。固定选厂规则；同父代/工厂的原九种厂内邻域各4次独立抽样，未改变算子。每父代重放1FE、36个候选各1FE；重复、增量复用和noop均收费。

实际调用冻结原IntraNeighborhoods等类，见[加载身份/JDK](../runs/action-feedback-probe-20261105-094303-818797/loaded-identity.json)。候选前只读父代的11个基础状态及5个疲劳状态特征，不预览任何候选；父代编码/目标与原付费记录逐项一致，原邻域不修改父代。全部14208成功FE、零失败，另14208次完整解码/独立合法性和完整时间轴精确QA；0新增来源搜索。源码、类哈希、输入和全部候选四向量保留在新目录，默认源码与主线未变。

两个留一来源seed交叉验证，训练集排除与测试父代物理等价的编码，包括跨厂交错等价；本批实际重叠0。每折96训练/96测试，每职责24。每个动作一个固定三输出ridge，训练特征标准化、截距不惩罚、lambda=1，不调参；标签为4抽样平均的原始相对三目标变化。选择按接收职责预测收益，CENTER沿用Direction.reward的三目标相对变化之和。

SHARED用96个跨群训练父代，OWN用24个本群；MATCHED_SHARED也严格24个，每个职责6个，分开样本数量和来源组成。BASIC_SHARED不含5个疲劳特征；ROLE_MEAN/POOLED_MEAN仅用动作均值；UNIFORM按均匀动作的期望评分；FIRST只是原第0邻域一次提案，不是完整VNS。ORACLE知道实现结果，只作上包络，永不作为可用方法。

主评分为选中动作4次抽样的**期望正单步职责收益**，不是挑最好抽样或合并4个孩子。另算相对请求前真实档案的期望单候选HV，参考点1.25/1.5/2；原始signed回归目标和positive评分的差异保留，不事后改目标。本项不模拟CENTER的PDDR接受或整条VNS，不证明后续价值。

## 近邻与剩余边界

多目标算子选择已有[FRRMAB（Li等，2014）](https://colalab.ai/publications/LiFKZ14.pdf)；按偏好重用向量反馈已有[Yang等的NeurIPS 2019工作](https://papers.neurips.cc/paper_files/paper/2019/hash/4a46fbfca3f1465a27b210f4bdfe6ab3-Abstract.html)。[DQNMOEA（2025）](https://www.sciencedirect.com/science/article/pii/S0952197625023000)的出版方摘要明确包括动态疲劳、四维编码和DQN选择局部扰动维度；本轮只核到公开摘要/方法预览，没有审计其付费完整实现。不能把“加学习器选邻域”作为本项目独有创新。

本次否定的是固定廉价线性反馈模型在已定窗口中的独立实用收益，不证明所有共享学习不可能。没有新完整算法、真正同时间比较、Li/强经典晋级或独立确认，最终goal仍active。
