# 动态共同模型：dynamic-append-v1

2026-11-01。已实现的新动态共同模型合同；必要正确性与联调证据见[前三步验收报告](前三步实施验收-2026-11-01.md)。

## 定义与继承边界

以李明哲第四章双资源分布式异构混合流水车间为基础，保留三个最小化目标：Cmax、TEC、TWC。实例和SUT来源、工人分阶段规则、每厂非空、首阶段四向量语义沿用《模型合同》。该版本是动态模型适配，不是原论文成绩复现。

动态解码采用确定性追加式策略，无插空、右移、主动等待和疲劳硬阈值。其可达日程受固定解码规则约束，不宣称覆盖所有含等待的可行排程。原静态canonical-v1保留，不能用β=0声称已退化为含插空/右移的原解码器。

## 物理与目标

工序工件j、工厂f、阶段k、机器m、工人w的基础时长为 b=(ST[j,k]/MS[f,k,m]+SUT[j,k])/WE[f,k,w]。S=max(前阶段完工,机器末完工,工人末完工)。该工人末次完工疲劳v_prev在空闲期间恢复，u=v_prev exp[-mu(S-Cw)]；首次使用时，从时间0的h0恢复至S。

持续时间d=b(1+beta*u)，完工C=S+d，末疲劳v=1-(1-u)exp(-alpha*d)。设置与加工均受同一开始疲劳系数修正：设置子时长=(SUT/WE)(1+beta*u)。机器和工人同时占用完整[S,C)，不在设置完成后提前释放工人。

TEC逐工序累加P_m*d及该机器内部空闲I_m*(S-Cm)；机器首次使用前gap取0，末工序后不计standby。TWC=Σ wage_w*d，不计空闲工资。Cmax为最终工序最大实际完成时刻。

alpha、mu、beta为非负有限参数；h0∈[0,1]，资源id局限于同厂同阶段。辅助工厂统计独立存放，不进入目标数组。

## 辅助疲劳指标

工作期暴露D_o=d-(1-u)(1-exp(-alpha*d))/alpha，alpha=0时为u*d。使用expm1及必要的小参数展开避免抵消。每工人暴露为其工作工序暴露之和；totalExposure为工人总和，maxExposure为最大个体累计工作期暴露。空闲与尾部恢复不纳入积分，未使用工人的工作暴露为0。

peakFatigue记录工作期间及初始时刻的最大模型内疲劳。它与累计面积不同，均作为辅助指标，不参与TWC子群目标和环境选择，也不外推医学风险。

## 编码、排序与增量

JS/FA/MA/WA均长N且按位置对齐；构造和遗传传递资源时按job身份读写。MA/WA仅编码首阶段。每厂首阶段按JS过滤，后阶段按上一阶段实际完工稳定排序，最早可用机器与工人分别选择，平局取最小id；继承上一阶段相同完工时的顺序。所有阶段使用相同动态物理内核。

工厂之间无共享资源和物理耦合。同实例/参数/解码上下文下允许复用完整未变工厂；变化工厂仅复用逐项相同的首阶段(job,m,w)前缀，随后重算后缀与该厂后阶段。不能依时间接近或疲劳近似相同提前截断后缀。构造器提供的准确首阶段前缀须与目标编码逐项匹配。

## 数据与计费

原benchmark缺SUT及standby，重建输入必须标注非作者数据。运行入口物化PCG64生成的SUT及具体疲劳参数，Java/Python读取相同实际值；不把不同语言中相同seed当作相同数据。现有36合格实例为开发资料，9个违反式(8)实例不得混入严格比较。

疲劳情景沿用原型时间尺度规则：基础时间尺度为median((ST/median(MS)+SUT)/median(WE))；alpha、mu除以该尺度，alpha/mu/beta逐工人乘独立[.85,1.15]合成异质因子，h0=0。weak=(.10,.8,.1)、strong_slow=(.45,.08,.7)、strong_fast=(.45,.8,.7)，前三项依次为alpha_per_base、mu_per_base、beta。beta0保留积累/恢复而仅取消时长反馈。全部情景为合成敏感性设定，不是生理测量。
