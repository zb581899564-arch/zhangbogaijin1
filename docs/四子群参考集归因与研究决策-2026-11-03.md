# 四子群参考集归因与研究决策

**保留四目标分工，结束“直接改变中央参考集即可稳定获益”的当前分支。** 参考集确实改变 CENTER 的接受，但收益取决于入口粒子和随机模板。没有足够证据冻结一个新选择器，因此没有启动两实例三种子小筛查，没有修改四子群、QGS、动态解码或共享主线。

## 影响结论的问题台账

| 问题 | 当前状态与证据 | 决策影响 |
|---|---|---|
| 评价、预算、解码是否失真 | 冻结文件、依赖 JAR 和记录的加载类哈希通过复核；两种模板共八臂的实际计费、前沿及三个参考点 HV 从原始输出复算一致。两条传播轨迹各 447,916 FE，均复现原路径档案准入。用隔离 classpath 重新通过完整/增量时间轴、FE 边界/失败、动态中断和检查点测试。 | 在本诊断范围内，未发现可解释收益翻转的计费或物理错误；这不外推到未测试的模型。 |
| 运行身份能否核查 | 传播进程的实测 CodeSource 和字节哈希仅三处观察覆盖不同于反账本；互换模板的 CenterRoleSwapProbe 确实产出 16 项块统计，冻结类字节哈希通过。另开零评价 JVM 核对该 classpath 中观察类和搜索类的加载优先级。 | 分开报告运行内加载证据和事后类路径检查；不把它们当作者发表版身份证据。 |
| 原作者基线身份 | 发表版启动参数、精确计费及部分原始数值输入仍未闭合；见[发表材料审计](QGS发表材料溯源与静态行为核查-2026-11-03.md)。 | 本轮只在共同重建模型上解释行为，不能恢复作者实验名次。 |
| 配对是否公平 | S/U 用原来相同的初始化、同一反账本槽位、共同入口背景；模板内逐槽 RNG 相同。两种模板各自的原配对均复现付费序列摘要和出口解。固定槽配额仍可能触发不同续跑次数。 | 可对比同付费预算下单阶段行为。没有同时间性能、自然预算或多种子泛化结论。 |
| 参考集效应的方向 | U 模板下，换 S 参考集对两种入口都提高出口解 HV；S 模板下，对 U 入口仍有增益，但对 S 入口在三个参考点均微负。 | 通过“会影响接受”的机制核验；未通过“稳定带来收益”的预设门槛。 |
| 某个物理子群是否是可用参考来源 | 同候选逐块交换能定位分数变化；55 点中央块常解释较多翻转，15 点成本块在一些臂较明显。但与等大小混合块相比，没有跨四臂稳定超过全部对照的物理块；翻转也不等于 HV 改善。 | 不据此定向加权、加大某个角色的参考配额或筛新参考池。 |
| 局搜出口是否进入下一轮 | 真正的下一轮追踪显示，SPECIAL 55/55、UNIFORM 53/55 个中央阶段付费出口通过选择；所有入选者都作为下一轮更新输入。第二全局块没有通过这些出口直接充当接收父代或引导输入的子代产生新档案准入。 | 不能把瓶颈说成“中央局搜解没活下来”或“没传到下一轮”；传递使用与新发现之间的因果增益仍未建立。 |
| 近邻与创新边界 | [原 HMOPSO-QGS](https://doi.org/10.1016/j.eswa.2025.130934) 已有边界与中心分工；本地合同明确原重建用四群全局结果作为 CENTER 的共同 PDDR 参考。[AREA §2.2.2](https://arxiv.org/abs/1910.07491) 已研究根据档案调整目标参考集；它通过目标距离和解关联做搜索，并非当前 PDDR 接受。另有[支配型多目标局搜](https://link.springer.com/article/10.1007/s10732-011-9181-3)的邻域与档案机制。 | 这些先例不能证明本项目的精确机制已被覆盖，但“换参考集”“用档案”“保留四群”都不能单独立成创新。实际改动未获准入，也不作完整查新或录用判断。 |

## 互换随机模板：参考集影响可复核，正收益有条件

复用同一实例 20_2_3_1、seed 8111009 的两个已付费入口，不新增截取。四臂每条 239,795 FE、1,705 槽，0 失败，总计 **959,180** 新搜索 FE。每个槽都恢复旧 SPECIAL 路径的实际 Java RNG 状态；两入口来源、两参考集来源完整交叉。SS 对自身原路径的评价序列摘要与全部 55 个局搜出口精确一致。U 模板的既有 UU 也通过同一性质核验。

下表是中央段结束时，固定入口，把参考集从 U 换为 S，保留解相对共同背景的 **HV 差值**（参考点 1.5）：

| 槽位随机模板 | 固定 U 入口 | 固定 S 入口 |
|---|---:|---:|
| UNIFORM | +0.004200 | +0.005231 |
| SPECIAL | +0.007125 | **−0.000223** |

在 S 模板，四臂中仅替换参考集能改变同候选接受判定的比例仍达 **4.40%–4.86%**。但是所有付费发现与保留不同：该模板的发现 HV 平均参考集效应约 −0.000102，且取决于入口。不能把先前“参考集平均影响约三倍”外推成对任何入口都占主导。

物理块归因是对同一候选/当前解算 PDDR 的只读反事实：只换一块，看是否重现换全套参考集的翻转；也反向恢复该块，看是否撤销全套翻转。保持各块人数 15/55/15/15，并与三套固定的等大小混合位置对照。例：SPECIAL 模板的 SS 臂，物理中央块重现 **60.14%** 的全套翻转，等大小混合中央块为 37.09%–57.10%；但 UU 臂物理中央块为 **55.50%**，混合块最高 **58.17%**。物理成本块也没有跨四臂稳定超过全部等大小对照。比例可重叠，不能加总当成贡献份额。

## 下一轮传播：确实使用，没证明带来更多好解

两条观察重放到原轨迹第 447,916 FE 的第二全局段末尾，各核对 5,000 条连续付费更新，合计 **895,832** 搜索 FE。与旧反账本的档案准入、首代生存选择及初始化一致，未改变搜索行为。

| 第二全局段可观察通道 | SPECIAL | UNIFORM |
|---|---:|---:|
| 中央局搜付费出口入选／可选 | 55/55 | 53/55 |
| 作为接收父代的子代数 | 55 | 53 |
| 作为个体引导输入的子代数 | 1,566 | 1,553 |
| 作为全局引导输入的子代数 | 896 | 1,564 |
| 含中央阶段已付费工厂片段的实际组装 | 62 | 93 |
| 上一行中进入外部档案的子代 | 2 | 0 |

通道会重叠，引导参数被送进更新算子不代表每次都遗传了其基因。SPECIAL 的两个新增准入都含中央阶段付费工厂记录，但不来自所追踪的入选出口片段；这不是“两个改进都由中央片段造成”的因果证据。固定共享规则可以使用中央搜索过程中评过的非出口记录，独立于粒子生存。现有数据更支持区分**被搜索发现、活到下一代、被实际取用、产生新前沿**，而不是统称“传播失败”。

## 完成决定与替代路线

- **本轮停止点**：预先冻结的稳健性门槛要求两个模板、两个入口及三个参考点的保留解 HV 效应都同向。实测未满足；逐块诊断也没识别出一个稳定优于等大小普通控制且有方向性收益的来源。没有新候选可冻结，两实例×三种子小筛查和正式实验方案的条件未触发。
- **近期替代**：复用 PDDR 的已验证等价式，考虑将 CENTER 候选接受从重算整个参考池两两排名，改成只数候选/当前解相对参考池的支配数和被支配数。一遍参考扫描即可代替二次比较；同候选探针已在实际轨迹复核判定一致。若另行推进，应让所有使用同一深局搜的对照同时采用该内核，并核对轨迹不变后再测实际同时间成本。它是工程优化，不列为算法创新；本轮没有接入。
- **下一项机制假设（未启动）**：保持四职责及已有共享，检验预算在角色间如何兑现。可先用已有按阶段付费曲线定位边际收益衰减，再预先固定一条允许更多轮次的阶段日程，和普通轮转及匹配局搜 NSGA-II 比较；阶段费用必须对齐，不从结果反向选择阶段或额度。没有独立收益就保留四群为研究架构，继续收缩论文主张。

本轮实际新增搜索 FE **1,855,012**，全部为现有两政策的隔离诊断；离线复核没有新增算法搜索 FE，Java 小型合同检查另列。未启动新方法筛查、扩量、默认主线变更或公开推送。
