# 动态疲劳拓扑诊断协议 v2（运行前冻结）

本轮继续独立机制验证，回答局部预测误差来自何处、完整疲劳反向何时比时间通道划算；不修改Java模型/优化器，不运行MOPSO/HV实验。共享v1动态前向和伴随，参数、数据补充来源与最早开工等限制保持显式记录。

## 验证集与候选

- 沿用v1的6个合格实例、SUT生成seed和三档合成疲劳参数（包括相同异质性），新父本seeds固定为 **11、29、67、137、307**，未参与v1。90个父本/场景。
- 连续微扰：固定随机抽4个首阶段工件，分别将标准处理时间ST乘 `1±epsilon`；epsilon为 `1e-5、.001、.01、.05`。每个幅度8个正负成对干预，四个幅度复用工件。其他实例输入、疲劳参数和编码固定，不因ST改变重新估计疲劳时间尺度。这是敏感性探针，**不是可优化的编码决策**。
- 合法局部池：16个单工件机器/工人修改或同厂相邻工件顺序交换。局部指编辑位置少，不保证异构资源造成的工时变化小。
- 合法较大池：16个v1规则的同厂两工件资源交换/顺序交换/插入/联合编辑，在新seed父本上重新生成。
- 每case六个池，共64个候选/干预；总计5760个。候选生成不查看目标、疲劳参数或真实拓扑，三档场景使用相同编码/干预。FA不变，纯JS修改的资源属性随工件移动。

## 三段误差分解

所有值使用同一个父本目标向量归一化，Cmax、TEC、TWC、均衡方向分别诊断：

1. `P`：v1廉价预测，旧前驱状态局部defect及旧完整伴随，真实重解码前固定并落盘；time_only使用相同前向停止疲劳反向。连续探针另记录 `grad_base*delta_base` 的纯切线预测。
2. `C`：候选首阶段真实重算，记录全部首阶段C/v及直接费用；只用旧后阶段的伴随在阶段边界作一阶传播，不在首阶段内再次反向。用于诊断首阶段近似的影响。
3. `B`：首阶段同上，后阶段维持父本机器/工人分配及资源前驱链，所有开始时间max与疲劳递推重新计算。它是可行固定资源顺序对照，逐工序验证；不同于把旧完工时刻原样搬过来。
4. `T`：共同完整动态解码器，对候选重新执行后阶段ECT/FAM。候选真值。

精确保存 `T-P=(C-P)+(B-C)+(T-B)`：分别表示替换首阶段近似、旧后阶段内非线性/max响应、改变后阶段调度策略产生的差。分解顺序固定，绝对分量可以互相抵消；绝对分量占比是描述指标，不是唯一因果贡献比例。`C/B`都不是主选择器，也不隐瞒其额外计算。

## 拓扑与分支标签

按工序稳定身份比较 `(factory,machine,worker,parents)`，分别计首阶段和后阶段变化。额外记录各厂各后阶段执行序列变化；独立资源工序的执行列表变序不一定改变依赖图，不混为一谈。

连续探针按全图分成“图和活跃分支均相同／图相同但max活跃前驱或Cmax终点改变／图改变”。合法编辑通常已改变首阶段图，按**后阶段**作相同分组，并保留首阶段改变数量。图未变不等于可微分支未变。

标签来自事后真值，只作误差分层，**不当成无需评价即可获得的在线筛选条件**。主选择质量仍在各个预生成完整池内比较，不按真值标签挑候选。

## 指标、费用与统计

- 误差：父本归一化标量的MAE、WAPE（总绝对误差/总绝对真实变化，无效分母显式为null）、每父本分层池内Spearman与可定义数量、三段绝对误差及抵消程度。保留无影响候选。
- 选择：完整疲劳伴随、时间通道、随机，在同一池上均匀平局/均匀随机的期望指标，统一拒绝变差。完整池接受收益、改善概率、regret、排名等沿用v1。
- 计时：本机单线程，组件预热1次+5次重复，保留每次值；完整父本trace可复用于伴随，候选完整解码只做真值/检查。诊断首阶段、固定后阶段、完整适应性解码分别计数。
- 单步成本代理：`(父本trace+伴随)/q + 候选生成 + 局部defect/评分/选择 + 子本trace`；随机使用minimal前向。q=1、4、16。**只有父本不变时才能复用**，接受新父本后必须重新计算；q>1是成本情景，不是假定搜索总能免费复用。
- 六个实例簇内配对，按实例→父本seed分层bootstrap2000次，各池/场景/方向/q分别比较单位代理时间接受收益。大量小样本比较只作描述，不凭某个正区间宣称总体显著或筛选最好场景。
- “导数准确”与“有优化价值”分开。连续探针即使预测准确，也不能直接作为合法候选选择收益；实际适用性要看合法池、收益大小、对时间通道的增量与实测成本。
