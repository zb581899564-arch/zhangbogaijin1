# v10解释边界：不能把v9子集结论推广到任意工厂数

发现时间：2026-11-01，v10计时正在运行、尚未分析收益。来源为第二关对原论文厂间原子交换与一般N1可达性的补核。这个说明不修改算子、预算、主比较或既有数据。

v9的F=2、N=3/4、各厂非空空间中，交换重绑定确实属于两次不同job强N1的N2，已作空间审计。v10推广至F=3—5，不能未经检查沿用这个包含关系。

## 最小反例

三个工厂各一个工件，首阶段每厂2机器、2工人。任意强N1只允许改本工件资源，不能迁空源工厂；因而任意两个不同工件的两次N1仍保持所有FA。交换两个工厂唯一工件则同时保持每厂非空、编码合法，却改变两工件的FA，故原子swap_rebind终点不在该N2支持集。资源重绑定不是造成这个反例的必要条件。

这也可能在更大实例的某次搜索状态中出现：只要所选两个厂均为单工件，原子交换的可行性与受限单迁移不同。不能因此断言所有普通复合都不足；允许额外缓冲移动的更长复合、原论文已有原子厂间交换，都能改变比较范围。

## 对本轮的影响

- v10推广器已独立直接实现合法原子swap和逐步合法plain，没有使用包含关系筛选候选，所以不需中断、修数据或重跑。
- v10原冻结协议没有宣称任意多厂支持集包含；v9的审计范围保留为v9，不回写成一般定理。
- 在v10结果解读中，必须把固定概率重权、候选费用与该非空约束造成的支持差异分开。
- 李明哲第四章原文已有厂间原子exchange；本反例本身不能转成首次性或新机制成功。
