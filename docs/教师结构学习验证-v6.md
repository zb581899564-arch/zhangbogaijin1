# 接收状态条件化教师结构学习 v6：评价质量提高，同时间优势未通过

**本轮确认了接收端评分的每次评价收益，但没有确认相对直接继承/随机选择的稳定同时间优势。当前版本不应接入整套算法，也不应作为已成立的效率创新。** 时间边界在主单元同时间下优于廉价评分；这不足以替代对低开销直接继承和随机控制的检验。

原始证据：[正确性门控](../runs/fatigue-teacher-validation-v6-20261031-201537-894734/completion.json)、[性能目录](../runs/fatigue-teacher-performance-v6-20261031-201641-372374/)、[完整汇总](../runs/fatigue-teacher-performance-v6-20261031-201641-372374/summary.json)、[全部单元表](../runs/fatigue-teacher-performance-v6-20261031-201641-372374/report.md)、[流式审查](../runs/fatigue-teacher-performance-v6-20261031-201641-372374/audit.json)、[独立设计/预算/源码审查](../runs/fatigue-teacher-performance-v6-20261031-201641-372374/design_audit.json)。设计见[运行前协议](教师结构学习验证协议-v6.md)。

## 比较了什么

从合格清单按(N,F)分层选择13实例，选择过程不读取v5收益；包含N=20/50/100/150/200、F=2/5/8、K=3/4/5。五个全新seed为8089、16193、32503、65011、130027，共65配对父本、13实例簇。只用强疲劳快恢复合成场景，TEC为主、均衡方向为同池补充。

每条运行先付费完整评价8个独立合法编码，按自身目标选最好的2个作教师，之后教师冻结。它们是独立机制用的elite donor bank，**尚不是完整PSO运行产生的动态pbest/gbest历史**。主单元最佳教师平均目标为接收初始值的0.9792，83.08%的case优于接收初始值；不要求教师必优，也不删除较差教师case。

每次抽取相同seed确定的2/6工件块；两个教师各提出顺序继承、顺序加完整资源元组继承，最多4个候选。非法迁空工厂明确拒绝，资源随job移动。按逐厂(job,machine,worker)完整顺序去重和去除中性编码，保留全部来源；无候选时显式noop并付费评价。**直接继承也在接收端真实重算疲劳**，没有用错误状态复制制造弱对照。

五条路线为直接继承（按教师自身目标选择）、廉价旧状态评分、精确首阶段＋时间边界、精确首阶段＋疲劳边界、随机选择。FA固定时沿用已验证增量内核；FA迁移时回退完整首阶段，后阶段边界仍是旧拓扑的离散外推，单列结果。

## 信息有效，费用抵消

在主单元的严格同池数据中，教师自身质量与接收端候选真实变化的平均排序相关仅0.049；廉价评分0.385、时间边界0.639、疲劳边界0.615。时间/疲劳的delta MAE约0.00434/0.00402，低于廉价0.01254。相关系数仅在有可比较排序的case计算，不能当作独立样本或等同于搜索收益；均匀平局期望与实际随机选择分别保留。

这份费用分解只定位当前实现的成本，不证明任何尚未实施的懒轨迹/缓存优化一定能扭转结果，也不据此回写本轮同时间结论。事后从冻结日志计算的候选数分布与时间/疲劳支持集合一致率另存[归因摘要](../runs/fatigue-teacher-performance-v6-20261031-201641-372374/additional_attribution.json)，没有再调参或重跑。

## 决策与边界

本轮支持“源教师的整体质量不能代替接收者中的结构评价”这一信息层判断；不支持“加入当前接收端边界评分就能稳定提高单位实际时间收益”的算法主张，也没有证据认定完整疲劳反向相对时间通道有稳定额外价值。

原idea的教师部分已完成这一版独立原型验证，不再是完全未测；但教师来自静态top2-of8、工件块随机抽取，尚未验证真正PSO历史、敏感性选块或完整疲劳链联合算子。FA迁移的旧拓扑外推、13实例/5seed、每计时单元一次、合成疲劳和重建数据限制全部保留。

当前不进入整套算法，不为了追正结果立即调整触发比例、挑块大小或追加另一套学习机制。若继续，应先综合本轮和v1–v5的信息/费用证据，提出独立可反驳的成本或结构假设；任何实现优化或新机制须另立协议，以直接继承和随机作为必要强对照，不能把未经验证的节省当免费计算。

整轮在线搜索实际合计1207.81秒，墙钟1458.47秒（约24.3分钟），JSON I/O累计10.46秒；正确性门控另耗40.34秒。公共加载、全部离线QA/真值/池再生和输出开销均包含在整轮墙钟中，未反馈搜索。所有原始记录、负结果和单位检查修正历史保留。
