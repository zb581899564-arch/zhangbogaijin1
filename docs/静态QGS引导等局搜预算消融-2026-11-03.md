# 静态 QGS 引导：等局搜预算消融

实例 `20_2_3_1`、seed `8111009`、原静态插空／右移解码、同一重建 SUT、standby=1、相同四群与 SO 算子。两臂均严格完成50万次实际评价。**Q表相对均匀抽引导动作的末点HV只高0.05465%；随机动作保留了上一轮静态局搜调整追回的约98.44% HV增量。** 结论只限本例、该seed和冻结的局搜日程；不修改默认四群或动态共享主线。

## 两臂只换哪一项

- Q引导沿用原ε贪婪Q表动作选择。均匀组在同三个动作中均匀抽取，不用Q值选择。三个动作始终是沿用上一引导、取组内最佳、在内部档案中二元锦标赛；保留粒子个体历史、PSO更新、边界和中央四群、候选选择以及局部搜索接受规则。随机组仍有全局引导，这是Q表选择策略的消融。
- 为保证两个终点的预算结构相同，先用一条单列的500000 FE记录运行重放已有外层30轮QGS，冻结每次访问的目标群、跨厂配额、VNS轮号、工厂、实际评价配额。记录运行的原有检查点与已完成的上一轮QGS精确一致。随后两个对照使用完全相同的隔离类、相同配额文件。局搜操作若在某槽内自然结束而还有余额，按同一规则继续在该槽内搜索；以固定配额截停。两臂均适用此规则，Q组无需续跑，均匀组累计触发1961次。该强制配额条件不同于让两个算法自由分配预算，且日程来自QGS锚点。
- 三个进程保存首次100次评价的逐粒子JS、FA、MA、WA和目标值，顺序和文件字节完全相同。三份账本的124次局搜访问、3818个跨厂／厂内槽逐项匹配，且与阶段成功评价计数独立对账。

采用既有归一化，主HV参考点1.5；50万处参考点1.25/2.0时Q相对均匀为+0.052%/+0.040%。经验IGD+末点分别为0.001433/0.002230，经验参考前沿取两臂50万有效前沿的非支配并集。两条HV曲线中途互有领先。Q组、均匀组搜索耗时15.61、14.16秒，单次不作同时间质量结论。

用原30次评价上限重建QGS的既有50万HV（1.003879）作参照，改用外层30轮且带Q引导的HV增量为0.036428，换成均匀引导仍有0.035860，保留98.44%。对既有现行NSGA-II（1.042448），两臂分别差0.205%与0.260%。这支持“这一轮追回的差距主要随深局搜配置出现，几乎不依赖Q表选动作”；不证明Q学习在其他配置无效，也不把局搜预算重分配的效果归给某个单独邻域、四子群或整个全局搜索。

正式两臂合计100万实际FE、零评价失败、585个返回解完整解码通过。配额记录另计50万FE和252次返回解验证；含构建、记录与两臂的墙钟49.17秒。Q引导重放与记录运行的所有检查点精确一致。没有运行动态候选，不替换主线。
