# 后阶段可控性与表示扩展合同（2026-11-05）

后续执行：已完成独立政策工程及单操作候选覆盖，两例未晋升，见[实际结果与停止决定](后阶段资源选择工程与候选覆盖结果-2026-11-05.md)。以下保留本合同形成时的范围与约束。

**当前只完成实际类/政策核查，尚未实现扩展编码、改变解码器或评价新策略。** 这是下一候选方向的工程与科学边界，不是性能通过记录。不得将“后阶段不能直接编码”说成已经解释了四群对同编码NSGA的差距。

## 已确认的边界

[零FE实际类审计](../runs/decoder-control-contract-20261105-094737-109500/status.json)记录实际DynamicDecoder、DynamicValidator、DynamicStageState、DynamicPhysics和DynamicSchedule的来源、class SHA/JDK及反汇编；0搜索FE、0解码调用。decoder的decodeFactory在首阶段使用ma[pos]/wa[pos]，后阶段分别调用firstAvailable；validator在后阶段同样强制earliest机器/工人，**既校验物理可行性，也校验具体解码政策**。不能仅改解码器、放松原验证器便宣称通过共同模型验收。

该事实与[v1–v6四向量范围](v1-v6证据与四向量可控范围.md)、[静态模型合同](模型合同.md)、[动态共同合同](动态模型合同-v1.md)一致。资源状态按厂/阶段独立，首阶段改变仍能经到达顺序间接改变后阶段，不能把“直接未编码”误写为“完全不能影响”。在首阶段逐厂工件顺序、资源和完整时间轴均相同时，固定确定性后缀只有一个；独立改变后阶段绑定不能由保持该首阶段物理状态的旧编码表达。

[阶段物理诊断](阶段物理结构与分配松弛核查-2026-11-05.md)中20工件8阶段的首阶段E/W份额约8.8%/11.6%，100工件2阶段约57.0%/54.6%，为检查控制范围提供动机，但这些份额不是贡献上界，也不是两算法差距的因果证明。[固定FA交叉失败](共同固定FA条件交叉结果-2026-11-05.md)和[跨职责动作反馈失败](跨职责动作反馈小验证-2026-11-05.md)不允许继续把“更强厂内四群”或“更聪明Q”当作已有结论。

## 新假设及必要对照

待检验假设：在不增加主动等待、插空、右移或新目标的物理规则下，显式允许后阶段资源选择，是否存在当前固定FAM规则漏掉的、有实际目标价值的合法日程？如有，再检验四个专业职责是否比同样拥有该选择空间的强经典方法更能利用它。

两个命题须分开：表示扩展可以增加搜索范围，**不自动证明四职责更好**。只胜过被限制的旧NSGA而输给相同表示的NSGA，不满足最终目标。阶段/资源重绑定本身是常规调度决策，不凭扩展基因长度声称新颖性。

## 实现前约束

1. 默认dynamic-append-v1和其原验证器/缓存完全保留。新政策/表示另命名；缓存、序列化、工厂组合键必须含全部后阶段绑定与政策身份，禁止把同四个旧向量而不同后缀的日程当成相同解。
2. 工厂固定、每厂非空、工件逐阶段先后、工人/机器互斥、局部资源id、首阶段四向量和Cmax/TEC/TWC物理公式保持。工序按已选资源最早可行时间启动，不引入主动休息或等待变量。改变的是可表达资源决策及解码政策，不能冒称逐轨迹等价的新优化内核。
3. 未指定后阶段覆盖时，必须对同一付费编码与原解码逐工序、所有状态/目标完全一致；保存首阶段轨迹后只改后阶段时，首阶段保持完全一致。所有候选严格计费，任何全解码预览也计入实际用途的费用。
4. 新验证器单独核对显式/默认绑定、资源可用、FIFO顺序和独立疲劳/能耗/工资公式。不能复用原“强制earliest绑定”的验收结论，也不能删掉原断言。先验工程未过，停止在工程层。
5. 先做小型表达能力/合法性见证，记录旧绑定、替代绑定、完整时间轴、改善与全部费用。若枚举全候选最优，那只是昂贵oracle覆盖上界，不是一次FE的免费选择器或同预算算法优势。候选数、普通首阶段控制、父代取样和门槛须在任何新结果前另行冻结；目前未启动此实验。
6. 只有确有实质可用空间，才设计全局/局部搜索如何共同操作扩展表示；保留四职责/原条件共享的隔离变体，并给NSGA同样表示、合法修复、局搜与评价内核。完整算法还要比较原共享、Li规范重建、角色/共享消融、真实FE和真实时间，再按既有门槛做未用实例/新seed筛查与独立确认。

这是与已失败池选择、固定FA分解和动作评分不同的“可表达决策”问题；也可能没有足够收益。无结果前不扩大实例、不替换主线、不将之写为已立住的创新，最终goal仍active。
