# 四子群局搜预算分配：深局搜、普通轮转与按职责分配

**本轮固定的多轮方案没有缩小四子群与匹配 NSGA-II 的末点差距。** 普通轮转在部分早期检查点提高四子群 HV，但 50 万 FE 末点较原深局搜低约 2.52%；按历史拐点分配末点低约 3.82%，也低于同轮数的普通轮转。不据本轮再调额度或扩量，默认主线未动。

## 旧曲线怎样定配额

零新增 FE：从旧 SPECIAL 首轮各物理群的付费档案准入记录重建累积 HV。每段按实际 FE 等分四份；以下为每 10,000 FE 的 HV 增量。预先采用同一规则：首个使其后所有分段收益率都不超过此前峰值 25% 的分段终点为拐点，否则记为整段。用反向账本 L_U 定配额，原 L_S 只作敏感性检查。

| 物理群 | L_U 四段收益率 | L_U 拐点（该段的比例） | L_S 拐点 |
|---|---|---:|---:|
| 工期 | 0.015990 / 0 / 0.004066 / 0 | 3/4（运行累计 53,874 FE） | 1/4 |
| 中央 | 0.012110 / 0.000838 / 0.001279 / 0.000029 | 1/4（130,080 FE） | 1/4 |
| 能耗 | 0.013219 / <0.000001 / 0.000011 / 0 | 1/4（326,415 FE） | 3/4 |
| 人工成本 | 0.006759 / 0.000807 / 0 / 0 | 1/4（392,638 FE） | 1/4 |

中央和人工成本的早衰减在两份旧账本一致；工期和能耗的位置互换。工期在 L_U 的第 3 段还有回升，刚超过旧第一段峰值的四分之一；因此不能把整张表解释为普适的角色预算规律，也不能将档案边际增量等同于该群固有能力。定配额和评估同属开发实例与种子。

## 六臂怎样配对

同一个 20_2_3_1、seed 8111009、100 个初始四向量和目标、固定动态疲劳模型、反向账本来源与提速后的线性 PDDR。每个日程都让四子群 SPECIAL 与 NSGA-II＋匹配局搜各跑一条。

| 日程 | 设计 | 四子群和 NSGA-II 各自阶段实际 FE（初始化／全局／跨厂／厂内） |
|---|---|---|
| 原深局搜 DEEP | 冻结 L_U，原长局搜槽和顺序 | 100／10,000／549／489,351 |
| 普通轮转 ROTATE | 4 轮，每轮 5,000 全局 FE、119,975 局搜 FE，厂内额度按访问人数均分 | 100／20,000／800／479,100 |
| 职责分配 ROLE | 与 ROTATE 完全相同的周期、顺序、访问数和工厂槽，只把厂内份额按旧群到拐点所花 FE 分配 | 100／20,000／800／479,100 |

两种多轮版每轮访问 100 个体，每个体 2 次跨厂评价。复用旧账本第一轮同一访问位置的 30 个厂内工厂槽，分成 8/8/7/7 发到四轮；同一组内按人数和槽数整分。每轮厂内预算（工期／中央／能耗／人工成本）：普通轮转 **17,967／65,876／17,966／17,966**，职责分配 **41,149／50,577／13,910／14,139**。冻结协议后才跑性能。四子群的 QGS、家族、共享、角色顺序和接受规则不改；NSGA-II 不引入分群繁殖。两种新日程互比可识别本轮群间份额的影响，和深局搜互比还同时改变了全局/局部及跨厂/厂内的分布，不能归为“轮数”一个因素。

六条各 **500,000 次实际评价、0 失败**，共 300 万 FE；模型计数、逐槽和逐群预算均核对，末档另作完整解码。两条深局搜复现此前全部 FE 检查点及末档编码。两种多轮版各跑完四轮应付评价；SPECIAL 的末次选择被 50 万 FE 硬上限截住，已付费末档保留，不把它写成四次完整环境选择。首次脚本启动缺少导入，在任何评价前退出，失败目录保留；补导入后新目录运行，没有额外搜索。

## 末点和同时间

| 日程 | 四子群 HV | 匹配 NSGA-II HV | 四子群相对差距 |
|---|---:|---:|---:|
| 原深局搜 | **0.850493** | 0.861381 | −1.264% |
| 普通轮转 | 0.829079 | **0.864670** | −4.116% |
| 职责分配 | 0.818030 | 0.863147 | −5.227% |

50 万次时四子群普通轮转较原深局搜降约 2.52%，职责分配降约 3.82%；在相同四轮条件下，职责分配还比普通轮转低约 1.33%。匹配 NSGA-II 的两种多轮日程末点略高于其深局搜，四子群的退化不是所有算法切换这份账本后都会发生的。参考点取 1.25 或 2.0，末点的差距排序也不改变。早期则不同：四子群普通轮转在 5 万和 25 万 FE 高于自身深局搜（0.765608 对 0.717424、0.818398 对 0.808420），但这些检查点均未超过匹配 NSGA-II，且未保留到末点。

职责分配在 1 秒时领先，但四子群已评 48,123 次、NSGA-II 只评 26,138 次；2 秒起领先消失，不能当作搜索质量或稳定同时间优势。六条搜索耗时约 4.55–5.45 秒；时钟结果为本机单次串行观察。末点差距并未改善；不继续用同一实例反复试分配比例。结论仅针对预冻结的四轮拆法和按拐点权重，不能否定其他分工或自然停止策略。
