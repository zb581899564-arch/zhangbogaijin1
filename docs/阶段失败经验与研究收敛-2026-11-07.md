# 阶段失败经验与研究收敛

2026-11-07。用户要求的阶段复盘；只整理已有证据，没有新增搜索、解码、指标重算或新机制。本文件不恢复Goal，不授权后续实验。四职责与原共享继续作为研究基础。

## 当前判断

局部正迹象需要分别经过普通对照、实际前沿增量和后续使用检验。工程正确、机制触发、局部改善、完整算法竞争力是不同层次，不能相互替代。

当前不应概括为所有设置都输NSGA-II：已有Linux 100_2_3_1 / 14910003的500k结果中，SHARE对匹配GOM的NSGA-II为HV+3.841%，对普通PA为−4.657%；其他实例仍有反例。这一例对PA的差距主要在100k—250k拉开，不能泛化为所有实例或唯一根因。详见[强对照轨迹诊断](强对照轨迹差距定位-2026-11-07.md)。

## 最近几轮反复出现的断点

|尝试|已经观察到什么|尚缺什么|
|---|---|---|
|增加全局、共享或其他资源供体|可用内容和候选改变|稳定优于普通供体流程的收益|
|改变FA统计来源|联合块明显改变|优于匹配随机分组的证据|
|精简编辑并迁移|部分编辑减少损害、可以局部迁移|优于同大小普通合法改动的实质前沿增量|
|保留权衡工作分支|Q确实成为工作态并继续优化|优于普通双起点、且能提交的新终点|

“变化充分”“接受更多”“有少量新点”只证明机制在工作。新机制必须解释为什么同样预算比普通流程更有价值。

1536真实FE＋36QA全部成功；9/12条Q支路更新，共16次接受；两个末点不被旧A0覆盖，却都仍差于原P的专业目标，可提交新终点0/12。人工成本群一例P成本62149、Q成本64175、末态64139，续搜有改善但未补回离开P的代价。互不支配说明存在取舍，不能证明取舍具有可恢复性或后续搜索价值。

## 研究推进方式的教训

几轮机制逻辑不同，却反复围绕相同成熟入口。它们有助于排除解释，但不能把多次相关失败当成多个独立反证，更不能据此否定四子群。应减少从单个局部现象直接追加机制的做法，把已失败假设合并收敛后，再判断是否有新的可干预缺口。

已有312条合格局搜出口出现记录全部进入下一轮并被QGS作父代使用，大量中央准入点也接受并继续使用，不支持“成果根本没接通”作为普遍解释。完整排程减少不等于资源/顺序信息全丢，也不等于外部结果档案漏记。仍未识别唯一性能根因。

成熟共同A0会使双向C多数相等覆盖；很小的绝对IGD+距离会放大百分比变化。需要同时报告绝对数、区域、覆盖分子分母、途中发现与工作终点，不按指标多数投票。普通双起点、随机分组和普通合法编辑应在最小方案中预先登记，不能只比弱对照或原始失败版本。

## 下一项讨论应回答什么

先围绕“为何PA在中段能持续形成有产出的后续搜索状态，而现有四子群体系没有同样兑现”收敛。新干预必须指出跨轮形成与延续链上尚未解释的环节，并明确它与PRE_FIRST、FA统计来源、供体合并、状态发布和工作分支的区别。现有记录无法支持时保留未知，不默认追加付费小试。
