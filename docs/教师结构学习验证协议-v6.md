# 接收状态条件化教师结构学习验证 v6（运行前冻结）

只检验教师结构候选的选择机制，不接入Java/PSO/QLS/QGS，不改变动态疲劳公式、目标或旧结果。固定完整评价次数和相同真实时间分别对照，不能同时把限时链称为同FE链。收益为正不是完成条件，不据结果换seed、块大小、阈值或教师生成方式。

## 数据、实例与教师

从36个合格实例按(N,F)分层，每组按stage排序，用该组在排序后13组中的序号模组内数量选取一个实例，得到13实例，涵盖N=20/50/100/150/200、F=2/5/8和K=3/4/5。选择不读取v5收益。SUT/profile生成索引仍采用旧6实例在前、新30排序追加的36实例映射，不改数据。疲劳仅采用强疲劳快恢复合成场景；TEC为主，均衡目标用于同池补充。

新父本seed固定8089、16193、32503、65011、130027，共65个配对父本、13实例簇。每条run在线生成并真实评价8个独立合法编码，按教师自身三目标在接收端初始尺度下的加权值选最好的2个，形成付费精英教师。这是独立机制用的elite donor bank，不冒称已运行PSO的pbest/gbest。每条run的教师生成、8次完整评价和排序全部计入时间及FE，之后教师冻结。

FA固定时，教师与初始接收者共享逐工件FA，随机化JS/MA/WA。跨厂迁移时，教师具有独立合法FA。全部方法采用相同源编码/seed和教师排序规则，记录教师质量相对接收者的分布，不要求教师一定优于接收者，不据此剔除case。

## 同一批合法候选和五种选择规则

固定2/6工件两种块大小，块由与方法无关的seed抽取。每个教师提出两种编辑：在接收者中该块原占据的位置上采用教师相对顺序；以及相同顺序加该块完整(FA,MA,WA)元组继承。块外资源属性不变，属性随job移动。最多4个候选，非法（含迁空工厂）明确拒绝，不随机修复。按逐厂完整(job,machine,worker)顺序识别不变与重复：只有跨厂全局交错变化而逐厂日程完全相同的编码也删除/合并，避免给直接继承塞入已知中性候选；保留全部来源，不用任何目标真值去重。全部为空时记录显式noop单候选并真实完整评价，不因无有效迁移而丢case或重新抽好块。

- `direct`：按来源教师自身的固定加权目标排序，同一最佳教师的合法顺序/联合变体在去重后均匀选择，不用接收状态评分。
- `cheap`：旧状态局部缺陷＋时间通道；大块编辑不沿用16缺陷的人为上限，检查上限为N，真实扫描与全部缺陷费用计时。
- `time`：精确首阶段＋下游时间边界。
- `fatigue`：相同精确首阶段＋完整疲劳边界。
- `random`：同一去重合法池均匀选择，作辅助对照。

FA固定时time/fatigue沿用v4精确工厂/前缀内核；跨厂迁移时明确回退完整首阶段，不扩展或绕过已验证内核的FA限制。跨厂候选的后阶段边界仍来自旧工厂/资源拓扑，属于更强的离散外推，不能宣称已精确分析迁移后的全部阶段；该模式单列预测误差与收益。所有方法始终在接收者内真实解码选中子本，疲劳/时间状态不从教师复制。

## 正确性门控与两层证据

先用旧seed23/53、全部36合格实例、2种FA模式、2种块大小，共288个case做候选合法性、继承边界、首阶段与完整候选C/v一致、FA固定增量/完整C/v/直接费用与时间/疲劳分数一致核验，候选数量及非法/去重/noop完整记录。单元检查包含job属性位置对齐、迁空拒绝、去重来源、noop、beta=0两边界一致、超过16缺陷大块、缓存失效、固定FE及截止。门控通过且源码/实例未变才用新seed运行。

第一层是同池单次选择：13实例×5seed×2FA模式×2块大小×TEC/均衡方向=520个case，每case五方法各独立运行1决策，共2600run。相同接收者、教师、块和候选须逐项一致。每run完整评价10次（初始1＋教师8＋选中1），真实计时。全部选择固定后才对该池所有候选做离线完整真值，计算实际接受收益、均匀平局期望收益、排序相关性和oracle regret；额外真值计费单列，不反馈选择。

第二层是实际接收链：同260个实例/seed/FA/块上下文，强快TEC下各跑24决策和0.5秒两种预算、五方法，共2600run。固定24时均为33次完整评价；限时FE自然不同，逐项报告。每次接受严格真实标量改善>1e-10，接受后所有接收端缓存失效，拒绝才复用。教师冻结，初始归一化尺度冻结。父本分歧后只共享候选生成规则与随机流，不再声称是逐项相同的池。

总计5200run，全部最终调度离线完整重解码与可行性检查；每步通过教师/块/合法性/分数支持集合/接受及版本记录重建，离线QA不反馈。

## 时钟与统计

从RNG和初始完整解码开始，计入8教师评价/排序、候选生成/合法性/去重、全部缓存/前缀/伴随/复制/扫描/汇总/投影、选中子本完整评价、接受/失效和内存日志。公共数据加载、JSON I/O、离线最终QA/候选再生和单次同池真值单列并计入整轮墙钟。setup也可消耗完预算，0决策的case仍保留。非抢占决策只接受完整子本评价在截止前完成的改善，尾部实际耗时计入gain/second。

主要单元预定为FA固定、2工件块、TEC。4项比较time-direct、time-cheap、fatigue-direct、fatigue-cheap，在同池单次实际收益、固定24、0.5秒三个层级共12项构成一个Holm检验族。每实例先平均5seed，枚举全部2^13种实例符号做精确单侧配对检验；效应区间为10000次实例→seed层级bootstrap95（未修正），统计seed20261124。其余块/FA模式、均衡方向、cheap-direct、fatigue-time及随机比较全部作预定探索性结果，正负均公开。13实例簇不等于65个独立实例。

单进程单线程串行，方法和预算/目标顺序确定性轮换；一次run/单元，不把计时重复当独立样本。保存新目录下的协议、环境、源码、源数据/重建SUT、教师bank、所有链/步/epoch、同池真值和调用计数、失败、实际预算与统计，旧v1–v5不覆盖。

这些证据只回答当前elite教师、合法块和动态模型下接收状态评分是否值得使用，不代表完整协同进化、多目标前沿或真实人体/原论文数值复现。
