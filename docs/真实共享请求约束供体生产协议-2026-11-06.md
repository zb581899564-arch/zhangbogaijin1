# 真实共享请求约束供体生产：隔离协议

本轮回答：真实接收请求的约束能否改变供体生产，并在相同新增评价预算下，比原职责接受、普通约束搜索和错配请求提供额外价值。默认主线、四职责、QGS、固定 FA 家族和原共享池规则不变。运行目录为 `runs/linux-request-conditioned-production-20261106-01`。

## 与旧失败方案的区别

旧 DEMAND 保存最近的紧工期 cap，用各厂池内最小工期决定工期群下一次搜哪个工厂；它没有改变供体接受判定。本轮不重新调整工厂访问比例。此前供体并集探针改变已有供体的可用范围，局搜后筛选探针改变父子选择时点；本轮使用共同的供体域和生成内核，只改变生产过程的接受判定。

真实 `compose()` 只有 `cap` 和 `eta`：cap 是接收父代 Cmax 的 0.9、1、1.1 倍；eta 是 0、1、4，组成固定九格周期。原请求没有 TEC/TWC 上限。本轮不虚构三目标约束，也不实施此前讨论中尚无真实字段依据的余量公式。

## 源证据与事前采样修订

原 Linux 日志有共享候选四向量，却没有请求当时完整的池。只读重放六条原轨迹至原成熟全局阶段结束：`20_8_5_1` 为 260880 FE，`100_2_3_1` 为 278560 FE，三个原 seed 为 16110003、16110037、16110069，总计新增源评价 1,618,320 FE。它们单独计费，不能称作零成本复用。

隔离副本仅在 `CooperationSupport.observeRequest()` 插入只读捕获。保留实际类来源、class 与依赖身份；核对所有既有逐次付费目标/阶段/准入、种群和选择记录、初始解、公共检查点，以及各源成熟窗口的 100P+5000 候选四向量与末档案。历史未在该截断点保存每一次候选的四向量摘要，不能把已有可核对项扩大成所有未记录基因的逐个证明。

600 个真实请求核查后，原“每源首四请求”全部落在周期 5–8，漏掉紧 cap。**当时探针 FE=0**。原协议、24 个原输入和核查保留；`amendment-01.json` 按请求周期元数据修正为每源选定家族的首次 0、4、8，覆盖 cap 0.9/1/1.1 与 eta 0/1/4。不按可行性、收益或后续结果筛选；不更换实例、seed 或原 cap 值。最终为 18 个请求，72 条科学轨迹，每条 512 FE，共 36,864 FE，比原上限减少 12,288 FE。

每个源按 seed 序号选择家族 0、1、2。各请求均在原 POST_GLOBAL 信息截止点重放，共同档案为该点已经付费的 A0。错配是同源、同家族三个历史请求的循环移位，全部在共同截止点之前已知。这是延迟批次条件实验，不等于即时在线反馈。

## 四臂与共同费用

| 臂 | 供体接受 | 末尾共享 |
| --- | --- | --- |
| ROLE | 原四职责接受 | 原请求、原选择器 |
| REQUEST | cap 违反量较小优先，相等时原职责接受 | 原请求、原选择器 |
| ORDINARY | 同 cap 可行性优先，相等时统一降低 `TEC/energyScale + eta*TWC/wageScale` | 原请求、原选择器 |
| SHUFFLED | 错配 cap 下违反量较小优先，相等时原职责接受 | 仍为真正原请求、原选择器 |

违反量为 `sum_f max(C_f-cap,0)/cap`。REQUEST/SHUFFLED 的生产接受只使用 cap，eta 仅用于原末尾共享；普通对照使用相同信息，并统一使用请求加权目标。CENTER 保持原 GOM 接受语义，没有另换中央方向。

载入原成熟 100P、原模型学习和工厂 FOS；只执行目标家族 5 个成熟受体，保留 M1/C2/E1/W1。共同调度为五受体轮转、原 FOS 子集与 PaMixingMove、接受后实时更新家族供体。511 次生产分配 103/102/102/102/102 次，第 512 次完整评价原共享池选出的组合；不可行时重评原请求父代，费用照计。该共同轮转是固定模型条件探针，不冒称原完整 GOM pass 或完整四子群算法。

池仍直接调用原 `FactoryPool` 的准入、容量 8、截断和平局规则。所有成功生产候选都进入结果档案和池观察，包括被内部拒绝者。进口已付费四向量的重解码只用于还原及核对状态；局部记录拼接的 QA 全局目标不进入搜索/结果档案，额外解码另计。原始来源 `paidFE=-1` 原样标为未追踪，不伪造出生 FE。

## 验收、评价和解释边界

工程 20 条，共 7,176 次尝试，其中两次预设注入失败。核对导入和工厂任务集、完整与增量时间轴、四臂起点/模型、重复及观察开关等价、FE 1/2/511 截止与第 2 次失败收尾。独立核查接受判定、全付费档案、逐次池更新、原共享选择与实际类身份通过后才进入科学批次。

固定实例尺度，HV 参考点 1.5 并检查 1.25/2.0；IGD+ 和传统 IGD 共用该批全部末前沿的非支配并集；双向 C 精确弱支配，相等计覆盖，并保留覆盖数和分母。主终点为 A0+所有新增付费候选的末档案。先对每 seed 的三个配对请求取中位，再展示三个源 seed 的原值、中位、范围和方向；请求不冒充独立 seed。各 cap 周期分层只解释作用条件，不替换总体终点。

沿用小试投入界限：中位 HV 改善 1% 或 IGD+ 对称改善 5%，同实例至少两个源 seed 同向；另一例不得有 HV 低于 −1%、IGD+ 低于 −5% 或 C 差低于 −10 个百分点的明确重大退化。C 与其他指标反向必须解释。普通对照能解释的收益不主张四职责独特贡献；错配对照不劣时不能主张请求匹配必要。机制少触发则报告检验不足，不换请求追正。

本轮无同时间优势、完整 50 万 FE 算法竞争力或创新性确认结论。无默认主线修改、扩实例、经典矩阵、Goal 恢复或后台实验。
