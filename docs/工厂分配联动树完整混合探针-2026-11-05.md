# FA统计联动树完整混合：小规模独立收益，跨规模必要关失败

**本轮没有得到完整新算法。** 学到的工厂分配联动树在20工件例确有超过同树形随机标签、单工件及经典生成核的独立收益；100工件例未通过相对增幅和经典控制要求，停止这份固定FA-MI/秩键混合程序，不进入种群演化实验。它不是完整GOMEA、HMOPSO或NSGA-II运行，也不是同时间比较。

## 1. 为什么换到完整混合过程

此前完整顺序—资源元组四角显示共同适配，固定物理前缀复制却未带来共同收益；CENTER出口几何判定改善原四群HV，但仍未追平同核强经典。本轮检验另一个具体问题：由种群工厂分配相关性学习的工件子集，能否比无学习的匹配子集更有利于一整段顺序混合。

不恢复上述失败规则。没有新HV接受、贪心教师对齐、预算轮转、Q奖励或共享选择器。原四子群、QGS和条件共享主线不变；本探针仅使用它们已经付费产生的来源快照。

## 2. 冻结来源、模型和完整程序

有效目录：[linkage-mixing-probe-20261105-142116-487815](../runs/linkage-mixing-probe-20261105-142116-487815/)。协议在新评价前冻结；复用两个开发实例和来源seed11730007/11730037的首代全局完成池，不重跑来源搜索。每池100实际生存者，四职责都已完成更新；80自由粒子训练和供体，20保护粒子只作已付费参考。

每池从四职责分别等距选8个自由接收方，共32个；每实例两来源为64个接收方。这是四职责等量的机制抽样，不是完整算法15/55/15/15比例，也不是新实例独立确认。

训练只使用80个按job还原的FA向量，不按改善筛样本。依赖为经验互信息，采用平均联动层次聚类、确定性合并平局，得到2N−1个子集，包含单点与完整根。该统计相关性**不等于目标函数的真实因果交互**，也没有显式使用疲劳状态或伴随信息。

候选表示按job绑定完整(FA,MA,WA)元组，并用各厂内(rank+0.5)/该厂工件数表示顺序。对子集同时复制供体完整元组与秩键，其余沿用当前接收者；按结果工厂、秩键、job-id排序。每步重新提取厂内秩键。若工厂被清空，原样回退父代并真实付费，不缩短子集、修复或补抽。

四种程序均从同一原接收者出发，各用2N−1次评价，同一步使用同一个原始同职责供体和预定噪声。内部接收后从新状态继续，拒绝则保留当前；供体池和100点参考始终冻结，不把其他程序结果反馈进去。

|方法|生成过程|
|---|---|
|FA_LINKAGE|按学习树的随机子集顺序，复制对应工件的完整元组与秩键|
|RELABEL_TREE|固定随机重标记工件，保留学习树每个子集大小及完整层次结构|
|SINGLE_JOB|按固定工件排列循环，每步只复制一个工件，评价次数与另两种相同|
|CLASSIC_KERNEL|调用实际setting0 ClassicKernelBridge.child，以当前状态和同一供体生成|

所有方法沿用原职责接受：CENTER为共同LINEAR PDDR，三个边界为各自严格标量改进，没有放宽平局。CLASSIC_KERNEL只是原经典生成核配合同一程序接受，不冒称完整NSGA-II；FA_LINKAGE也没有原排列GOMEA的完整依赖度量、重编码/缩放、强制改进或种群生命周期，不冒称其复现。

## 4. 主指标是完整付费程序的收益

每个程序的全部2N−1个候选相对于原5100FE付费档案计算联合HV增量，reference1.5和原冻结尺度。这里单位明确是一整段已支付39/199次评价的程序，不把联合体积冒充一个候选的增益。终点单点收益另列；结果不加入来源池或评分背景。

事前必要要求两实例均满足：学习树平均程序增益至少比随机标签树高10%，不低于单工件和经典控制；至少16/64接收方有正收益，配对胜数多于负数；两个来源seed分别不弱于随机树；reference1.25/2.0对随机和经典方向非负。通过也只允许另立演化种群协议。

|实例|学习树平均程序HV增量|对随机树|对单工件|对经典核|对随机胜/负/平|有收益接收方|
|---|---:|---:|---:|---:|---:|---:|
|20_8_5_1|0.00097238|+78.146%|+19.250%|+307.627%|30/17/17|44/64|
|100_2_3_1|0.00402114|+6.381%|+11.705%|−5.265%|34/30/0|63/64|

百分比均是**等评价次数完整程序新增量之比**，不是完整算法HV提高78%或308%，也没有与完整NSGA-II比较。

20例两来源分别优于三个控制，全部登记条件通过。100例两个来源均略胜随机树，但没有达到10%必要幅度，且均弱于经典核；reference1.25相对经典为+9.828%，1.5为−5.265%，2.0为−15.423%，稳健条件也失败。不能只展示小参考点或小规模的正结果。

职责分层全部保留，不把事后较好角色拼成新算法：例如100例MAKESPAN的经典核均值0.005293、学习树0.000511，而CENTER学习树0.004497、经典核0.000591。它们说明程序效果随职责/接收状态变化，但尚未通过事前独立的职责选择协议；CENTER单工件控制在100例也高于学习树，不能忽略它来宣称中央模型成立。

## 5. 决定、局限和下一项工作

**停止这份固定FA-MI/厂内秩键捐赠程序，不启动完整演化种群试验。** 不换依赖公式、秩键、接受或平局、供体群、树大小/根、窗口、seed和门槛求正。保留小规模独立收益，失败不外推为全部GOMEA或模型进化方法无效。

该探针只学了工厂分配相关性，资源绑定和排列依赖没有被模型直接学习；并且是冻结供体的一次完整程序，尚非多代种群搜索。它既没有证明四职责来源的净收益，也没有β=0对照或疲劳信息的独立价值，更没有强经典/Li/原共享的同FE/真时间优势。

下一项先核对成熟方法的完整表示及原始实现，明确哪些是本项目新适配、哪些属于已有模型机制。已定位[原作者源码目录](https://homepages.cwi.nl/~bosman/source_code.php)，其中分别列有C语言PermutationGOMEA及C++二进制MO-GOMEA；本轮只读取页面，未下载源码包，不能把当前简化程序称为这些实现的替代品。

[2016年原作者论文页面](https://ir.cwi.nl/pub/25069)研究排列GOMEA；其[作者版索引](https://homepages.cwi.nl/~bosman/publications/2016_expandingfromdiscrete.pdf)还给出相对顺序/邻接依赖、重缩放与重编码等机制，当前FA-only程序并未实现完整这些机制。另有[排列与分配联合调度的模型进化方法](https://www.sciencedirect.com/science/article/pii/S0305054822003112)，本轮核对到出版社摘要，不能称全文算法审计已完成。联动学习和排列—分配结合本身都有先例，不直接构成四子群的新贡献。

后续须先建立原方法身份、混合表示/合法性、内部多目标语义和实际计费合同，再决定是否另立完整全局架构的比较；不在本轮失败程序上继续换一个度量。研究目标仍为可行完整算法和公平强对照、新实例新seed及独立确认，未缩成某项工程检查。四职责、既有共享、默认主线和全部正负证据保留，goal继续active。本轮无文件下载、上传、远端任务或公开推送。
