# 四子群动态疲劳调度：独立研究审核包

请先读 [研究全貌与结果](RESEARCH_BRIEF.md)，再把 [Pro 审核任务](PRO_REVIEW_PROMPT.md) 原样交给审核者。[代码与复核索引](AUDIT_MAP.md) 指向具体实现、历史文档和本包的可复算证据。原研究项目 README 保存在 [PROJECT_README.md](PROJECT_README.md)。

我们在李明哲第四章 HMOPSO-QGS 基础上研究动态疲劳条件下的目标分工和四子群协作。项目当前能证明一部分机制有效，但还没证明完整方法在公平对照下有稳定竞争优势。欢迎审核者推翻这里的技术解释；请把可定位错误、证据不足和研究取舍分开。

| 路径 | 内容 |
|---|---|
| `src/`, `research/`, `scripts/` | 项目主源码、独立局部机制试验、经典算法适配和实际运行入口 |
| `baselines/`, `data/` | 审核所需的少量兼容层源码、原 jMetal 许可说明，以及本项目使用的实例主体 |
| `docs/` | 建模合同、论文与代码映射、原先提出的方向、各轮协议和结果、文献索引 |
| `runs/` | 最近 50 万 FE 诊断的冻结输入、逐次运行回执、档案和局搜账本；早期实验按批保留分析与审计，并保留关键失败 |
| `review_tools/` | 可独立执行的核心证据复算器；不启动优化器 |
| `MANIFEST.json` | 收录文件、来源、大小、校验值及本地账户路径脱敏标记 |

这是供私下学术审核使用的快照，未发布。没有打包论文全文、作者原始交付仓库、编译产物、依赖 JAR、完整本地 Maven 缓存或早期大批量原始轨迹。项目源码与当时冻结副本同时保留，差异要按运行身份区分。历史命令、classpath 和旧链接有意保留来源用途；部分路径仅在原工作区可用。现有结果可以在本包离线复算；从零重跑完整 Java 搜索还需要原兼容工程和依赖，详见复核索引。第三方源码和实例的公开再分发权未核实，本包不授予其许可。
