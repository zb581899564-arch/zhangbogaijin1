# 固定供体支持域诊断

仅在Linux隔离执行，Windows只开发、传输和查看。默认算法不引用本目录。

- `structure.py`：资源—键支持、物理链成员判断、含平局的穷举夹具。
- `preflight.py`：六个冻结来源零FE核查；小实例枚举并去重。
- `run_oracle.py`：冻结预算、编译独立Java入口、截止/失败工程、计费候选。
- `closure_data.py`：逐条输入/输出对账、局部Pareto裁剪与组合见证。
- `analyze_closure.py`：共同参考集、HV/IGD+/IGD/C、独立HV及完整见证QA。
- `audit_domain_boundary.py`：初始FA和资源支持收缩的只读核查。
- `audit_same_fa_witnesses.py`：后续探索性同FA已付费见证核查，单独交付。
- `finalize.py`：费用对账、报告和不可覆盖的传输归档。

组合依赖复用`research/composition_oracle/frontier.py`与`volume.py`，冻结到每次运行的代码快照；指标与解码依赖均指向已验收Linux锚点。入口拒绝覆盖结果；首次0FE编译失败通过显式`--resume-pre-evaluation`修订继续，原快照保留。

结果见`docs/固定供体支持域穷举与下一步-2026-11-06.md`。穷举的3,580次解码真实计费；代数组合不是可免费嵌入搜索的新算法。
