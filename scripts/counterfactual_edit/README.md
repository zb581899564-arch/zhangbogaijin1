# 固定成熟父代的四原子反事实拆解

仅用于隔离诊断，不改变生产算法、四职责、QGS或共享。

- `freeze_cases.py`：按既有方案取8个正对、8个匹配负对和10个其他来源负例；在新评价前冻结26对、全部16格编码及事件前档案。
- `cf_common.py`：Linux路径、只追加输出及独立四向量编码。
- `execute.py`：JDK17/Java8编译、实际依赖身份、先52次端点QA，再364次真实计费评价。任何失败停止，不补预算、不换样。
- `audit.py`：实际加载类、输入身份、固定FA、原子掩码及79,360条工序记录的只读核验，不调用解码器。
- `cf_classify.py`：严格支配、编码冗余、条件必要性和最小正收益子集；各类结果可重叠，不构造加权总分。
- `analyze.py`：每格原始目标、A0/事件前/已有父子/旧末档案的单点增量，以及统一参考集下的HV、IGD+/IGD和双向C。
- `evidence_audit.py`：匹配负例、事件前档案及物理重复的独立只读核验。
- `export_report.py`：416格、156项命名控制、26例分类和逐来源诊断并集导出；不执行评价，不把数量不同的诊断集合当成同预算算法。

Java入口为`src/algorithms/diagnostics/counterfactual_edit/`的两个独立类。共同完整解码器每新格仅调用一次，原父子各一次QA；时间轴校验不额外解码。输入通过Python与TypedScheduleGenome双重编码核对，重复格仍计费。

运行证据：`runs/linux-counterfactual-edit-20261106-01`。原完整/增量时间轴验收复用上一轮冻结证据，当前端点须与旧目标逐位一致；不是额外执行一遍364次QA。
