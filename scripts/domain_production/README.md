# 成熟入口下的同FA域外生产诊断

Linux-only；不接入默认算法。固定两实例、三个已有来源和q0，同一成熟P100视图，仅五个固定家族受体进行有限生产。

模块职责：

- `protocol.py`：运行前冻结、旧域平局更正与身份核查。
- `campaign.py`：编译、19工程、18科学顺序运行及原GOM桥接。
- `audit_generation.py`：从输入重建完整合法目录、Java RNG与两工件联合提议。
- `audit_trajectory.py`、`audit.py`：复用原独立接受/池核，逐候选重放并对账类身份。
- `audit_extensions.py`：两新臂随机骨架、生成器计数和失败pending补查。
- `analyze.py`：共同参考集、三个质量端点、最佳域外单候选、预定条件解释。
- `finalize.py`：费用对账、表格与不可覆盖归档。

Java代码位于`src/algorithms/diagnostics/domain_production/`。原ROLE、FactoryPool、动态解码与RunContext复用冻结Linux锚点。支撑Python模块也来自已验收的旧冻结来源；不替换其历史记录。

本轮总预算77318尝试（科学73728、工程3590），仅一次预设故障；额外82279完整QA单列。结果为停止固定两工件生成器，不能当作所有同FA域外结构无效或四子群无效。
