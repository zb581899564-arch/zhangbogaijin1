# 已付费结构诊断（Linux，只读）

本目录不调用搜索或解码器。输入是冻结的域外生产轨迹，输出写新运行目录。

- `survey.py`：重建父代和接受历史，区分A0覆盖、物理变化与末端存留。
- `features.py`：同FA的资源/厂内顺序变化及工厂分量检查。
- `gain_trace.py`、`details.py`：真实时序HV账本、同父代负对照及入口几何位置。
- `paid_closure.py`：已付费工厂日程的有界、精确代数Pareto闭包；不生成已解码的新成绩。
- `finalize.py`：独立HV/分量加总检查及审阅包。完整原始派生数据保留Linux。

本轮按观察结果依次冻结`source-v1`至`source-v4`，属于探索性分析，不声称预登记假设检验。所有报告与原停止结果分开保存。具体费用、结论和未执行方案见`docs/已付费结构归因与下一假设-2026-11-06.md`。
